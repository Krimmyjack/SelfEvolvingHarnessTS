**目标**:补当前证据版图唯一缺口——"新密封、Scope 匹配场上的正向迁移"。非机制重做;卡与协议一律沿用现役冻结件。

## 1. 候选选择(结构盲选;元数据阶段禁读任何数值/标签)

- 池 = timeseriesclassification.com 官方单变量档案清单。
- 过滤(全部可由公开元数据机械判定):二分类 ∧ 等长 ∧ 单变量 ∧ 官方 TRAIN 行数 ∈ [40,400] ∧ **总点数(全 split 行数 × 序列长度)≤ 100,000** ∧ 序列长度过注入模板相容门(从 `cls._inject_v2` 常量与 0.10 修改帽机械导出,执行者引 file:line,禁现场发明)∧ 名称 ∉ 本地 `data/ucr_task_context` 40 件 ∪ `data/ucr_conf_downloaded/ROSTER.md` 全部名称。
- **字典序取前 3 = C1/C2/C3,一次写死**;过滤轨迹全文(逐名放行/排除+理由)先于任何下载写入选靶工件。
- 主线不设名单预测(站规:对外部档案元数据无可靠先验)。

## 2. 密封纪律

每 zip 落库即记 URL / 日期 / 字节数 / **sha256**(2026-08-28 sha 基线新规);未轮到者不开封;zip 不入 git。

## 3. 顺序考规则(冻结)

按序对 Ci:

1. 下载 → 结构载入检(冻结三类结构失败:下载/打包失败、loader 拒载、长度低于模板最小常量)。**结构失败 = 该槽死亡,如实报,不递补第 4 件**,顺延下一候选。
2. 开封(单独记录时刻/首读范围)→ 按协议对 TRAIN 注入(`fit_only_artifact`,模板原件)→ 算冻结 pattern view(0 LLM、0 consumer fit)→ **卡 Scope 机器判定**(SA-1 同源 scope-v2 单例卡 v0,AST 原件)。
3. **不匹** → 记录逐叶差异表与结构事实,该靶停用(不跑任何臂、不再读),顺延下一候选。
4. **首个匹配** → 能力考,CAP-1 骨架逐字沿用,仅泛化两个常数:TEST 子集 = min(官方 TEST 行数, 500) 行,`sorted(random.Random(20260828).sample(range(n_test), k))`,清单 sha 入册,只开一次;held-out 材料线 = `max(0.005, 1/k)`。其余照旧:TRAIN mod-4 对半双门(材料线各 `max(0.005, 1/40)` 按实际行数换算)、三臂 Static / A3 冷 h0 / A5-adaptive(K0 起源 + SA-1 同源卡 v0 + R1-R3)、每臂 LLM ≤15 / fit ≤25、判词 `CAPSTONE_POSITIVE/NEGATIVE/NEUTRAL` 三分阈值照 CAP-1 §6。
5. **反钓鱼硬条款:首个匹配靶考完即停批**——无论判词 POSITIVE / NEGATIVE / NEUTRAL,不得续开下一候选,不得重跑。
6. **三候选全不匹** → 判 `SCOPE_COVERAGE_LIMITED`,书面承认当前卡 Scope 覆盖有限,停止搜索,不追加第 4 件。

## 4. 全量报告义务与预算

- 每次开封无论结果全报(含不匹靶的逐叶差异);禁选择性汇报。
- 预算:下载 ≤3 zip / LLM ≤60(能力考 ≤45 + 冗余;选靶与匹配判定全程 0 LLM)/ fit ≤80 / 墙钟 ≤3h。
- `BACKEND_UNAVAILABLE` 或预算越界 → 停,无科学判词(照 CAP-1)。

## 5. 不入本件

按值/按族预选候选(开封前无法判族,系密封固有代价,本协议以顺序开封将其转化为累积条件化证据);CatsDogs(计算门排除,sol 原令维持);任何机制/阈值/菜单改动。
