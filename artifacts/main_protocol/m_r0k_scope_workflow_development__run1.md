### 4. 两条线各自最值得继续 / 应停止投入的具体理由

**Scope 线：应停止在本谱系、本课程上继续搜子句。** 理由不是「没搜到」，而是**已经搜完**：从这个祖先出发的合法一步空间是「祖先 + 至多一个校准子句」，24 对已穷举、5 个校准产物已全部评分；后 16 单元上 **L2（合法空间内事后最优、整段固定）= 不修订**，两个面都是；**L2 − L3 = 0**，两个面都是。也就是说**选择规则已经拿到了这个空间里能拿的全部**，剩下的差距不在选择，而在空间本身。要再动，只能扩 Scope 类（>2 子句或非阈值几何），那是另一个需要先裁定的决定，不是本包能推进的。

**Workflow 线：值得继续，但下一步不是加候选，是先解决选择证据面。** 理由：空间里**确实**存在一个在边界前证据上明显更优的程序（W2，+0.079460），对齐规则**也确实选中了它**——本包唯一的选择失败发生在「证据面 → 权威面」的迁移上（Support +0.014708 / delayed −0.022731）。在证据面问题解决之前继续加候选，只会把同一个失败放大：候选越多，用一个会翻号的面去挑选就越危险。

## 五、同覆盖随机保留参照（⑤）

对 `missing_fraction>=0.05`：逐单元取与它同覆盖 `k` 的、从**祖先自己选中集合**里随机抽的子集。

## 六、Workflow 线：合法性、一个恒等发现，与三候选读数

**合法性先核，非法就记原因、不放宽规则、拿到评分后不换候选。** 三个候选全部合法（注册表在册、`forecast ∈ allowed_tasks`、公开参数 schema 接受、typed DSL 接受、长度 ≤ 2）。Scope 固定为祖先 `z_peak>=3.0`，Consumer、训练/serving 双通道、域外 raw 回退不变。

### W3 与祖先逐位相同（恒等，不是「效果相近」）

`outlier_mad → period_median_complete(24,3,2)` 在 **42 个 (unit, face) 条目上全部与祖先程序逐位相同**（`program_per_view` 的 `repr` 相同），21 个单元两个面行为相同。机制是机械的、可复核的：`outlier_mad` 第一步就是 `interp_nan`（`operators/s1_outlier.py:44`），执行后窗口里已无 NaN；`period_median_complete` 的第一道判断是 `if not missing.any(): return raw`（`operators/s1_impute.py:151`）⇒ **它退化为恒等**。

**结论**：本包的 Workflow 候选集合有 **3 个不同效果**，不是 4 个；**顺序不是自由参数——插补必须在前**。这与 AGENTS §5.1 记录的顺序效应同向，但本包给的是**机制**，不是一个增益差。

## 七、oracle 三层（四件事逐条交代）

## 八、三问的直接回答

**问 1 · 本包明确列出的合法候选中，是否存在保留收益、满足风险和覆盖的修改？**

* **Scope：没有。** 合法一步空间已被完整枚举（24 对 → 5 个校准产物），5 个在 21 单元与后 16 单元、两个面上**全部**低于父版本；权威面上最好的一个也丢掉 −0.063438。
* **Workflow：合取意义下没有。** W2 在证据面上保住并提高了收益（后 16 Support +0.014708），但它在权威面上 −0.022731，**同时**抬高受损数与最坏单序列伤害、少过 2 个门。若只看效用、只看 Support 面，答案是「有」；这两个答案的差本身就是本包最重要的读数。

**问 2 · 只使用边界前证据的选择规则，能否选到值得的修改，还是应该 NO_REVISION？**

* **Scope：能，而且正确答案就是 `NO_REVISION`。** 对齐规则给出不修订；L2 整段固定最优也是不修订；L2 − L3 = 0（两个面）。原规则（被处理行分母）给出 `missing_fraction>=0.05`——一个事后被证明差 0.063438 的选择。**分母是这两个裁决之间唯一的区别。**
* **Workflow：不能。** 对齐规则用同样的边界前证据选中 W2（表观优势 +0.079460），而权威面上它劣于不修订 0.022731。失败点是**证据面**，不是候选空间（空间里确实有更好的），也不是目标函数（同一个目标函数在 Scope 线上是对的）。

**问 3 · Scope 与 Workflow 的剩余机会分别是什么？**

* **Scope：只减少处理量。** 排除精度 0.1948–0.2857（delayed），排除正收益的代价是避免伤害的 4.7–7.4 倍；权威面上不净恢复资格（最好的候选是 0 恢复 0 丢失，其余各恢复 1 丢 2–4）；对同覆盖随机保留只多 +0.0186，而过门率反低于随机。
* **Workflow：提高效用（仅在证据面上成立）+ 极零星的资格恢复，真正的空间在逐单元选择。** W2 在证据面提高效用、在 pos 23 恢复一个门；但权威面净亏、风险变差。有意义的剩余空间是 L2 逐单元换程序的 +0.039 / +0.042，以及 L1 放宽上界指出的 2.4–2.9 倍几何空间——两者都要求一个**逐单元/逐序列**的判断能力，不是再加一个整段固定的候选。
