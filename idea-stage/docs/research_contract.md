## Core Claims

1. **H**: In a frozen one-edit neighborhood, useful chronological headroom exists only if a complete finite-space evaluation finds a later-safe repair selected without recipient outcomes.
2. **S**: An edit-response transfer rule beats information-matched absolute-utility history only if the rule is **not** algebraically \(\arg\max g_e(P')\).
3. **A**: Agent vs equal-budget fresh search is **out of this package**.
4. **Limitation**: Success of H/S does not complete A5 or authorize sealed evaluation.

## Method Summary

Freeze a finite Workflow one-edit neighborhood of the existing DSL (including abstain). Split **donor** evidence from **recipient** decisions on separate training cohorts (origins inside a cohort are reencounters, not independent units). After each eligible recipient conflict, select using then-available evidence, validate on an unused face, freeze, then score a later reencounter against parent and identity. Compare a deterministic history rule to matched absolute-utility history and equal-budget fresh search. Report utility, four risk lines, coverage, and cost. Count all eligible conflicts; incomplete cache is UNKNOWN.
