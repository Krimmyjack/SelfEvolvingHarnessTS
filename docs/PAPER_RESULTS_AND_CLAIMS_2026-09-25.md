## 0. 统一口径

- **指标**：预测线为相对“未经准备的基线”（不增强，或 Time-MoE 的 192 点零样本）的误差降低百分点（pp），三域（电力 / 交通 / 太阳能）等权；括号内为 95% 聚类 bootstrap 区间；“胜/同/负”为逐案例计数。
- **测试身份**：预测线 40 个 Test 案例与学习案例实体、时间都不相交，但已在多个开发包里用过 → 写“disjoint from the learning cases / development revalidation”，**不写 unseen、held-out benchmark**。真正从未评分过的只有 TSFM 的 40 个新预测起点，以及正在运行的分类 Test（12 个从未打开过官方 TEST 的 UCR 数据集）。
- **零反馈**：部署时 Fast Agent 看不到任何下游分数；卡在 Source 学习、Select 选定后冻结。

## 3. 不能写的（现有证据不支持或已被否定）

- 域卡可靠胜过共享卡（MLP +1.37、Time-MoE +1.72，均跨零）；“每个域需要独立 Skill”。
- 超过最佳固定程序 / 固定上下文（Time-MoE Test 上的 +3.25 在新起点未复现）。
- 条件化 / 动态构造带来收益（卡臂未交付条件化方案）。
- 学到的经验在所有 Consumer 上都优于常识（DLinear 打平）。
- 预测 Test 是 unseen / held-out benchmark。
- PatchTST 上卡有收益（按用户要求摘要不提 PatchTST；正文如出现，只作为“准备空间小时收益消失”的边界证据）。

## 4. 分类跨任务验证（运行中，DEV-CLS-AUG-OFFLINE-SKILL，§5.12）

- **设置**：UCR 24 个独立来源；Test = 12 个官方 TEST 从未被任何旧线打开过的多分类数据集（交付全部冻结后一次打开，是全项目唯一真正留出的测试）；Source 8 / Select 4 来自 TEST 曾被旧线打开的来源、以二分类为主 → 实验同时包含类别数偏移。FCN（重实现）；11 个固定程序（Jitter、Scaling、MagWarp、WSlice 及两两组合）；六臂：不增强、无卡、朴素卡、经验卡、Source 最佳固定程序、冻结随机程序；Macro-F1 绝对 pp 差，独立单位是 12 个数据集（3 seed 不算独立）。
- **已观察到的中间事实**：无卡 Agent 在 20 个数据集上 17 次交付 MagWarp 或含 MagWarp 的程序（Source 7/8、Test 10/12）、3 次 Jitter、0 次不增强（系统性偏好，与预测线的“无卡偏差”同形）；两张朴素卡都以“默认不增强、避开 MagWarp/Jitter”为主。结果预计 17:00–17:30。
- **结果出来后的写法取决于读数**（事实条件，供 Planner 定稿）：
  - 若经验卡 − 无卡区间不跨零：可写“同一离线经验机制迁移到分类，在来源互斥的多分类数据集上改善零反馈 Agent”，并注明类别数偏移与 12 个数据集的样本量。
  - 若只胜无卡、与朴素卡或固定程序打平：只能写“纠正无卡偏差”，不能写经验优于常识。
  - 若经验卡 ≈ 无卡或更差：作为“跨任务迁移的边界 / 失败案例”报告，摘要保持“时序预测”范围。
  - 不增强对照若显示增强整体无益（FCN 增强空间小），应与 C1 的“准备空间”框架一并解释，而不是归为方法失败。

## 5. 摘要与正文措辞约束（沿用摘要 v2 的核对结论）

- “test cases disjoint from the learning cases”可以写；不写 unseen。
- “matching the best fixed programs selected on source data”可以写；不写 exceeding。
- 23 / 8 pp（NoMix，Test）与 30–48 pp（Time-MoE，Source）不是同一批案例。
- Time-MoE 的上下文收益只与它自己的 192 点零样本比较，不与 MLP / DLinear 的绝对误差并表。
