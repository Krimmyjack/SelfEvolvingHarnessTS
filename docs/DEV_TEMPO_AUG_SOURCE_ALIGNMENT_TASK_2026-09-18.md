## 1. 本包要交付什么

把 TempoPFN 中有明确源码依据的一批非 Mixup 增强，接入现有批级 Harness，支持构造、检查、共同训练和比较有限组合。交付后，下一包直接做同域 Workflow/Skill 的形成与使用比较。

本包完成以下四件事：

1. 更正上一包过强的解释；用已有预测简要检查峰值误差，不重跑旧实验。
2. 接入 7 个源码有据的增强原语，完成必要的一致性核验。
3. 贯通现有七工具和有限组合 DSL，使用脚本模拟 Fast 验证工作流，不调用实验 LLM。
4. 在四个已曝光开发 Job 上运行两份事先规定的组合，最多 28 次新增真实拟合，确认材料能被现役 Consumer 正常消费并取得实际读数。

这是工具供给与集成包。正收益不是接口验收条件，也不要求本包显著胜过 Fixed 才允许后续 Skill 研究。负结果仍完整报告；数值错误、权限或绑定错误必须修好。

不做新 Mixup、不扩 TSFM/LTSV、不改 Consumer、不做另一轮全算子效果枚举。

### 4.2 本包保持 240 点窗口几何

沿用现役增强探针：每个合法父对由 192 点输入和 48 点目标组成，增强作用于联合 240 点训练窗口。

- 原版整条合成序列与我们的训练窗口都是原语可接受的序列输入。固定 L=240 是明确的任务适配，不宣称复刻其完整语料分布。
- 同一时刻在不同重叠窗口里得到不同增强是窗口增强的含义，不自动构成数据错误。
- 本包不同时迁移为“672 小时整段 T 增强后切窗”。后者会改变扰动相关性、长度参数及缺失填补的可见范围，需要单列几何比较；不能把这部分增益混入原版算子对齐。
- 日期从原始数据的时间元数据绑定到每个窗口。240 小时也可包含周末；不要求每个窗口出现月末。不从行号 0 假设星期，不在日期缺失时默认日频。
- 日期绑定若失败，暂停日历原语及依赖它的组合；不要换成“随机一天平移”。
- 训练缺失补全、合法父对和 scaler 沿用现役 Baseline-Linear 路径。不得在适配时偷偷改为整段补全。
- 原父 X/y、训练窗口数量与顺序保持原样；每父对最多一个子视图。子视图 X/y 可以一起改变，真实 C_A/C_B/E 标签始终不变。
- 所有预测输入仍用公共 Baseline-Linear，不在评价输入或真实未来上施加随机增强。

### 4.3 本包不接入的部分

- 新 Mixup、多源 donor、OU/其他合成生成器。
- 时间反转、取反、微分/积分、量化、在线 NaN 注入：本次缩小范围，不下“这些必然有害”的结论。标准化值为负不等于物理负值。
- 原版随机预缩放及额外全局 scaling/noise：保持现役 scaler，暂不叠加。
- “改动太小则丢弃重抽”及质量筛选：暂不启用，不删父窗口，不变相重加权。记录零改动/别名即可。
- 单独归一化增强后输出、额外截断非负、缩短训练、调 weight_decay。

因此整体名称为“TempoPFN 来源算子的自然时序适配”，不是“TempoPFN 原版整条增强管线复现”。

### 4.4 随机性与一致性

材料随机性与训练 seed 分开。给定 Job、完整 plan 和材料种子，材料冻结一次，各训练 seed 共用，不每训一次重新抽增强。

不允许 Fast 通过改 seed 反复抽材料直到满意；相同语义的方案必须重用同一材料。沿用或扩展现有语义缓存键，不加 Hash。记录实际顺序和随机实现，恢复不重新生成另一份材料。

直接复用 torch 实现时，对原版与 wrapper 保存/恢复完整 RNG 状态（包括对象自己的 NumPy Generator），同输入同状态比较即可，不必为了测试改写原函数。
若跨库移植，再以显式随机参数/随机抽样记录对齐；只设置同一个整数 seed 不足以保证 torch/NumPy 输出可比。

## 5. 接入 Harness 的可编辑范围

复用 overview / inspect_data / build_material / inspect_material / evaluate / compare / commit 七工具。

- 原语目录、公式与训练协议由开发执行者实现后冻结。
- Fast 生成完整批级方案，可选不增强、单步或最多三步，允许用已有合法 T 特征谓词对实体分组。使用现成 predicate/compiler，不新建特征系统。
- 不开放任意 Python，不新增算子源码编辑权限，不开放材料 seed 或任意参数分布。
- 第一版每个原语只有 source 参数档，避免同时做强度搜索。后续有证据再加有名字的适配档。
- 一个组合内原语不重复；顺序采用本包固定执行顺序：
  regime/shock → calendar/amplitude → resample → censor → random_conv。
  同类 regime/shock 互斥，calendar/amplitude 互斥；选中的总步数不超过 3。
- P_NoMixRecipe 作为公开、参数冻结的配方预设接到同一 build_material；Fast 可以选择它、检查它和与自构组合比较。它只调用同一七原语，不保留基线专用的私有能力；先不开放修改其概率分布。
- inspect_material 至少返回实际作用步骤、修改比例和归一化 RMS、X/y 分开读数、少量前后片段及零行为情况。不把改动大小写成效用分。
- evaluate 仍比较整份材料共同训练的宏损失，并保留配对 seed、origin 读数；Fast 可提交任何已真实评估的候选。不得强制以 C_A argmin 覆盖 Agent 的提交。
- Slow 的后续编辑面仍是观察、构造、实验组织与决策指导，不修改上述执行器、Consumer、评分或标签权限。

本包只用脚本客户端演示：观察 → 构造组合 → inspect_material → 真实评估已有材料/重放合法读数 → compare → commit。脚本轨迹标为接线测试，不冒充 Agent 学到 Workflow。

报告主读数：
