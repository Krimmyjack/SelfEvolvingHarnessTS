## 1. 中心问题(论文措辞,采 sol)

> 在不同 Task、Consumer 和 Pattern 下,同一 Harness 能否利用各任务自己的历史经验,
> 更快、更安全地达到正确的数据就绪决策,并根据后续 Gain/Harm 持续修正自己。

多任务主张定稿措辞(2026-08-28 23:3x 入典):一台 Harness、N 个任务、各任务经验独立
成池且条件化复用、跨任务只查隔离与无负迁移。跨任务正向知识迁移不在关键路径。

## 3. 已落定裁定(D1-D5,sol 2026-08-28 23:4x)

- **D1** 三任务非对称:预测 = 正向效用与适应效率主结果;分类 = Skill 生命周期与修订
  证据;AD = 清洗伤害/正确弃权/安全(利用既有 12/12 负结果)。修正主线旗标 1:
  非对称角色下 AD 为**最廉腿**(守卫机器现成,验收读数=四臂正确弃权),非最长杆。
- **D2** 分类腿降权:非 UCR 补源出关键路径;必要时后补轻量 fresh 复现。
- **D3** Stage 3 = 单 Surface 有界 pilot(§6),入论文次级主张。理由:任务目标明含
  Instruction/策略更新,全放 future work 缺一块。
- **D4** 预测 fresh 池一次性批量冻结。资格四标准:序列量、反馈容量(容量门,以仓内
  冻结常量为准)、自然异质性、新鲜度(从未开封)。按预注册顺序开封;
  **禁逐个追正例**(CAP-2 教训成文)。
- **D5** 指标:主读数 = 固定课程预算下累计 held-out regret、held-out utility、
  harm 与 worst-series、错误晋升/正确弃权;效率读数 = 到首个安全有效 Skill 的
  consumer fits、time-to-threshold、fit 墙钟;LLM 调用与 probe 数分项报告。
  **禁任意合成总分**。预算记账单位 = 课程级(经验臂省下的调用可花在别处,摊销才可见)。

## 4. 考场难度:三档预注册梯度(sol 修正采认)

在 development 数据上预划 易 / 中 / 难(发现难度或风险),主实验三档全含,
预注册方向性预测:

- 易:A5 **非劣**(不得输给 A3/Static);
- 中:经验开始节省成本(fits / time-to-threshold);
- 难/险:A5 效用与成本优势扩大。

结论形态与条件化论题同构:**经验收益本身是条件化的,随发现难度、反馈噪声、可摊销
长度变化**。现有两锚点:cls SA-1(冷发现不可靠 → +0.686)与 forecast r2(冷发现
3-4 调用即中 → 0/微负)。难度操作化候选(池盘点后冻结):冷发现命中期望调用数、
天真探测误导率、反馈噪声水平、课程长度。**禁只取难档**(评审防线:不为 A5 定制
考题),**禁只取易档**(C5b/C5c 不可测)。

## 5. 主线护栏(G1-G5,v1 新增)

- **G1 C5b 受测性前置门**:冻结数据池前,在 dev 池预估**修订触发基率**(冲突场/
  负反馈/挤占事件,每课期望次数);低于阈值(拟 ≥2/课,协议另冻)则加长课程或换池。
  S2a 冲突场三重不可得的教训升为设计门:不可测性必须在设计期发现,不得在正式运行中
  现场发现。
- **G2 pilot/密封防火墙**:Stage 3 pilot 只用 development 池;被 pilot 触碰的域
  永久排除出 Phase 3 密封池。
- **G3 可编辑面排除安全层**:pilot 可编辑 Surface 仅限探索/分配策略;双门、容量门、
  harm 阈、越权守卫、隔离守卫**永不可编辑**。演化不碰安全层,站规级约束。
- **G4 预算形状**:三档混编进同一课程(预注册配比),不按档开课;consumer 轴仅
  预测腿全展开(pooled vs per-channel ridge),分类 ridge/kNN 作困难/敏感性案例,
  AD 三 consumer 只承担安全读数。预算表超限时预注册裁剪顺序:消融 > 档数 > 域数,
  **永不裁臂**。
- **G5 归因边界**:Consumer-blind 消融同时切断 Observation 可见性与 Scope 条件化,
  归因只到「整机 consumer 条件化」,不拆层(拆层归未来工作)。

## 6. Stage 3 pilot 协议(D3 落定,细案另冻后呈 sol)

- 种子 = 已发生的真实失败:S2a r2 受益单元 4,供给卡挤掉更优自发现
  (反事实 −0.1206,`s2a_g1_run1_r2.json`)。
- Surface = probe 位在「历史供给候选 vs 自主探索候选」间的分配策略。
- 三臂:No-edit / Random-legal-edit / LLM-edit(依失败轨迹提议)。
- 接受门:LLM-edit 在后续单元 regret 与成本**双非劣且至少一项改善**、harm=0、
  越权=0;单轮,不重掷;不论成败入论文(负结果照录)。
- 完成即冻结 **Harness v2**(= v1 + 至多一条被接受的策略编辑;拒绝则 v2≡v1),
  v2 为主实验唯一被试。
