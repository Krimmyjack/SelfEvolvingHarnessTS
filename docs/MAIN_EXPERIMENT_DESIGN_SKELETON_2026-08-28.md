## 2. 第一设计原则(从 S2a r2 成本分解直接导出)

**经验只有在冷发现「贵、不可靠、或有险」时才有付酬空间。**
r2 实测:冷发现 3-4 次 LLM 调用即可靠命中 hampel/MAD 族修复;此时供给至多打平,
且机器开销使 A5 反而多花调用(A3 19 / K0 21 / A5 23),受益单元 4 反事实 −0.12。
若主实验沿用这种"便宜发现"设定,C5 必然再次空心。

主实验必须至少满足其一(可组合):

- (a) **探测预算紧**:每单元 LLM 调用硬上限(如 2),冷发现不再必然命中;
- (b) **缺陷场误导性**:自然异质/复合缺陷(注入同质性教训已入典),天真探测给错方向;
- (c) **反馈嘈杂**:错误晋升有真实代价,谨慎(经验携带的先验)可测;
- (d) **课程加长**:≥15 单元,摊销可见,单次方差(0.29/位同象)被稀释。

**量表族三分**:效用(regret / held-out gain)+ 适应成本(LLM 调用、探测数、错误晋升数)
+ 安全(harm、越权、隔离面)。成本族为 C5 主读数——sol 原 S2b 量表族收编于此,任务内使用。

## 3. 三条腿(各任务经验 → 同任务新域)+ 跨任务面

- **预测腿(主承重)**:electricity/traffic 池训成经验;新域密封考【决 D4:候选池待盘,
  如 ETT/exchange 类】。若要补 forecast 修订环(C2),须自然异质缺陷场,不得注入(已入典)。
- **分类腿**:UCR 族内密封已 `POOL_EXHAUSTED`(CAP-2 终局)。选项:非 UCR 源【决 D2】,
  或降权为"机制已证、主实验轻复现",以预测腿主承重。
- **AD 腿**:线不存在,系 sol 路线夹带的新范围。【决 D1】2 任务或 3 任务论文;
  若 3,AD 线建设为最长杆(参照 forecast 线达到 S2a 用时),须最早启动。
- **跨任务面**:只查隔离 + 无负迁移(每对任务守卫面,应全零);不设正迁移主张。
