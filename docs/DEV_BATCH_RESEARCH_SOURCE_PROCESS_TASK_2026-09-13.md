## 1. 本包要回答的问题

**过去的研究过程，经 Slow 整合成一项实验设计指导，能否让 Fast 在变化后的整批训练材料上，用相同拟合预算产生和交付更好的完整方案？**

知识流为：
合法历史研究轨迹 → 一次 Slow consolidation → 冻结的 experiment_guidance → 新 Job 的批级 Fast 研究 → 共同训练与整体效用。

本包只检验一项 Source-derived 过程指导的开发级复用，不命名为完整 A3/A5 课程；Target 内不更新共享知识。H0 Fast 允许完整任务内搜索，不能把它叫作 A3。未来完整 A3/A5 仍需 Target 边界更新与独立形成轨迹。

这是一项候选机制试验。Fast 尚未稳定胜过 Random，不作为禁止本包的前置条件；本包也不因提示词合法或 Skill 被加载就晋升 M3。旧包的“完成即停止／不启动 Source”继续约束旧包，本任务是用户讨论后提出的独立新包，不重启或改写旧包。

## 3. 公共工具事实修复

在所有 Fast 和本次 Slow 获得的同一份公开工具说明中，明确：

- R：在同一实体的原始父训练对中随机错排，无自配、一一映射。

## 7. 冻结预算和执行顺序

每 Job：公共 None/Fixed 各 3 次；四种 Fast 各最多 2 个新完整候选 × 3 seed；Random 同样 2 × 3。
**上限计划 = 2 × (6 + 4×6 + 6) = 72 次物理拟合。**
这是整个包的总数，不是每臂 72 次。提前 commit、自然别名和合法缓存可减少实际拟合；节余不换成更多候选。

|资源|上限|
|---|---:|
|物理拟合尝试|74，含最多 2 次同配置非科学故障重试；正常计划 72|
|每 Fast Job 普通请求|16，含纠错|
|每 Fast Job 工具尝试|24|
|每 Fast Job 新候选评价|2，均为完整共同训练|
|Slow|1 次形成，最多 1 次明确契约纠正；KEEP 不重抽|
|全部逻辑 LLM 请求|130 = 8×16 + 2|
|全部 HTTP 尝试|260；单次传输最多原请求重传 1 次|
|usage token 停止边界|3,000,000；未知 usage 停止后续收费调用|
|活跃实验墙钟|10,800 秒；单 fit 子进程最多 300 秒|

模型沿用当前授权中转及 cpa-grok-4.6，请求与实际返回身份分别保存，预期 grok-4.6-build；不换模型。只从运行时环境取 key，不写入文件、报告或命令参数。无收费探活。token 是按已返回 usage 控制的停止边界，在途请求全部计账，不称后端保证的硬 token 限额。

拟合串行。顺序：
- a89：F0 → F_generic → F_source → F_program → Random；
- a93：Random → F_program → F_source → F_generic → F0。

Source 可用时无论第一个 Job 正负都跑完第二个；不因结果不理想修改 prompt、增加种子或替换作业。不同顺序用于减少固定运行顺序影响，不构成随机化实验。

保留已有缓存语义：公开基线可共享，私有候选只在本臂去别名；不跨臂泄漏候选。分别报告物理拟合、候选评价、缓存命中和 LLM 成本。Random 的拟合成本不是 0，所有臂只是拟合上限相同，不能声称总计算成本相同。

## 8. 冻结与失败语义

1. 公共语义、Generic、Source 证据白名单、P* 选法、Source 原输出、运行配置先冻结。
2. 所有 Target 分支完成／明确终止后，冻结全部 commit。
3. 再对全部已完整拟合候选打开 C_B，作为延迟诊断；无 argmin 覆盖 commit，也不回到 Slow。
4. 所有合格候选的 E 预测全局存盘后，一次性开放 E 评分。最终实际交付仍取已 commit 的第一 seed 模型，额外候选评分只供外部诊断。

传输故障、合法 KEEP、scope 未匹配、解析／校验失败必须区分。方法未完成不能以 Fixed/None 兜底标 COMPLETE；保留已发生的花费与有效前缀，主比较 UNKNOWN。正常主动 commit None/Fixed 是合法完整结果。

公共接口缺陷在正式 Target 收费调用前修；收费开始后不改变实验语义。非方法性的报告展示错误可在训练结束后修复并核对分数不变，不重训。身份／账户错误、信息墙破坏或无法解释的模型绑定问题暂停受影响部分；全局预算／权限问题停止全包。其余方法级失败隔离后继续健康分支。

## 10. 结果如何读、如何收口

主要效用仍为全 32 实体 normalized MSE 宏均值，方向统一：基线损失减 F_source 损失，正值为 Source 更好。
每 Job 列齐各臂交付第一 seed、三 seed 原值、均值、配对差及 seed SE；C_A/C_B/E 分列，不删难例，不以中位数替换主指标。

主要研究读数固定为各臂已 commit 完整方案的三 seed E 损失均值，主要差值为 F0 损失减 F_source 损失；同时必须报告对 F_generic、F_program、Fixed 和 Random 的差距。第一 seed 的实际单模型交付另列，若与均值方向不同必须明说，不在两种口径之间择优；三 seed 平均不代表交付集成模型。配对 seed SE 只刻画固定候选条件下训练随机性，不能解释为 Source/LLM 跨轨迹置信区间。一个 Source 抽样、每臂每 Job 一条 Fast 轨迹，仍只是开发级试点。

过程问题逐项回答：
- Slow 依据哪些实际历史事件提出了什么可复用指导？
