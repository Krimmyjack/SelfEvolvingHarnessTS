## 3. Slow 的材料与修改：方法差异只放在怎样利用反馈

### 3.1 中性母表：先固定案例，再附效果

按上述完整 roster 与 u9/u10/u11 固定案例及顺序，不能先挑受损部署或困难序列。
材料含：当前窗口公开特征及公式/范围、已实际可见的工具事实、完整 typed 候选和选择、
实际交付/合法性回退、程序对服务窗及共享训练材料的改动事实、测量可用性和来源。
仅能从渲染标签重建的历史程序须标明这一来源，不能把猜测当精确配对。

为避免只观察到 P 却让 Slow 猜 Q，附第一包**机械公共菜单**在这 60 个形成情境中
已经取得的完整逐程序读数；菜单仍为 23 个默认单步算子加 identity，不从 LLM 赢家
列表构造。缺项可以用相同 scorer 在本包预算内补评形成窗；全部 planned 项都列出，
未测是 UNKNOWN，确定性不可执行与拟合故障分开，不因收益差删项。
额外形成窗补评最多 300 fits，不求完备 oracle；缓存未提供的反事实明确未知。

R/C 获得相同全部材料、origin 主效果和 +48 持续性效果，两面角色明确；不得用 +48
为 origin 的动作贴“正确”标签。菜单得分是历史形成反馈，不是复核窗的当格评分。
每个共享测量只存一份，按语义键关联，可用紧凑长表减少重复，不能暗截为前 60 行或
只给模型失败而不给成功。材料超出端点容量时先做无损去重/结构压缩，不静默漏案例。

所有 Slow 都知道真实部署机制：Fast 用当前合法观察和工具决定，之后无 Support
兜底；执行前仍有确定性合法性检查。单序列损失来自完整准备—训练—服务管线；
“服务窗改动少”不等于没有训练侧效果，动作计数不能替代效用因果解释。

### 3.2 四个版本

| 版本 | 此次新增效果信息 | 修改方式 | 回答什么 |
| --- | --- | --- | --- |
| F | 不进行此次更新 | 父知识冻结 | 没有更新时怎样 |
| R | 完整真实效果 | 强普通反思，一处局部指导修改 | 普通反思是否已经够用 |
| C | 与 R 逐项相同 | 显式围绕成败/动作差异形成比较式决策指导 | 比较式组织是否有增量 |
| C-minus | 相同中性事实，但去掉新增效果 | 与 C 相同权限、模型与预算 | 增量是否依赖这些新增效果信息 |

**R 不是弱提示**：要求根据经验改善未来无反馈 Fast，并保留有效行为；允许自行比较
程序、提出条件或反证。不要限制它不能进行 C 所用的推理。

**C 多出的只是学习要求**：指出哪个已观察差异值得解释、能用什么部署可见证据
作区分、修改哪段指导、预期改变什么行为、什么效果会反驳建议；配对读数存在时
优先用相对价值，不存在时明说假说。例子中的具体阈值、程序和赢家不得注入模型。
不规定必须“弃权”或必须“竞争”，不预先把修改全部导向提议面。

**C-minus 必须干净**：不只是去掉 gain 数字，还去掉损失、风险结果、胜者/接受/
效果拒绝标签、按效果生成的组名排序及相关反思。可以保留不读 Outcome 的合法性
与执行事实。母表由全部预定案例构造，而非先按失败抽样后删数字。本包 Part B
候选形成无当格反馈，有利于减少反馈驱动候选池的间接泄漏。共同 K0 中旧知识不删；
此臂只表示“无此次新增效果”，不声称“从未接触任何反馈”。

### 3.3 允许修改什么

复用 AGENTS §5.4 的四类软指导对象：ADD 情境化指导；PATCH 已有指导正文或
applicability；PATCH bootstrap 指导正文；PATCH proposal_guidance / selection_guidance。
只呈上当前快照实际存在且可编译的面。每个 Slow 分支最多形成**一处实质修改**。

归因大类只作标签，解释可错，修改面由模型选择。任务/工具执行前置可以硬匹配；
效果假说可写入正文由 Fast 根据当前观察核查，不强制所有特征都变成检索阈值。
允许模型看到形成母表的基率和候选条件计数；R/C/C-minus 使用同一工具，C-minus
只能看不带效果分组的数量。不提供 u12/u13 条件覆盖来让 Slow 调条件。

不开放任意代码、特征计算器、算子、Consumer、风险/裁判、候选槽数、检索 top_k；
不改冻结 Program 卡，不赋予供给/执行权限。指导可描述应考虑的算子和观察流程，
但不是硬供给一个冻结赢家。没有观察工具就不编造其存在。原始跨轨迹 Episode 只进 Slow。

允许保持不变或弃权；只准因确定性格式/合法编译错误修正最多两次，不准根据复核
效果重问。R/C/C-minus 各有相同上限；失败和无修改均保留，不只报告成功候选。

## 5. 评价与分析：有限课程的配对效应，不制造统计精度

主终点固定为 `deployment_gain_at_origin`；+48 固定程序持续性单列辅助，不择优换面。
每格先对完整 20 UID 计分，再对 u12/u13 等权；g1/g2 分别报。
主比较 C−F；同时完整报告 R−F、C−R、C−C-minus 和相对 D-new-fixed / D-new-safe。
若某臂按零暴露等规则未运行，对应实测比较 UNKNOWN，不伪造一个完整四臂结果。

同报覆盖、伤害计数/既定比例、最坏伤害、每单元既有四线读数、UNKNOWN、LLM/fits/
墙钟。不改 min_treated=5，不把 raw 的合法性说成满足正向处理覆盖；不据本包评分
自动批准生产 Skill 或在后续窗口启用胜者。

每个配对须同 UID、origin、训练配置、面；缺 assignment、缺测、传输/执行故障分开。
计划人口有未知时该主均值/配对差为 UNKNOWN，可读子集只能另附诊断，绝不替换分母。
重复引用共享预测不增加样本；有程序标签不代表 typed 参数和作用区相同。

行为链报：修改呈现→观察/试执行→typed 候选→选择→实际交付。呈现的预定义子群
用打分前的共同 Context 冻结；按“最后选得不同/后来受损”定义的子群仅作事后诊断。
未呈现的序列也可能受检索竞争等间接影响，要比较实际视图/候选，不先写“全是噪声”。

采用外部评审 C 的核心口径：

- 实际固定课程的配对差是描述量；重复调用期望、新实体/时间泛化是另两个目标。
- 分列 UID、(UID, origin)、程序/训练拟合共享关系；不把 320 行当独立 n，也不把
  两次更新叫跨域复现。两窗/两组不足以给可靠功率、假阳性率或稳定噪声地板。
- 报逐单元及最大正/负贡献，附逐 UID 留一敏感性范围即可；不建贝叶斯/自举平台。
- `delta_all = p*delta_exposed + (1-p)*delta_unexposed` 是分解；仅在无间接效应时
  可简化为 `p*delta_exposed`。MATERIAL=0.005 是效应量尺度，不是显著性门槛。
- 有限样本没有显著差异不等于 R/C 等效；也不自动支持保留更复杂的 C。
