# 给 Pro 的调研与思考任务书：如何评价数据对当前 Consumer 的训练价值

日期：2026-09-13。
性质：研究问题重审、原始文献调研与下一轮最小实验设计。本轮不执行新训练，不调用实验 Agent，不改现有协议或历史结果。
委托目标：请独立判断，不替现方案找理由，也不把“得到稳定正号”当作验收条件。

## 1. 用户真正要解决的问题

用户的原话是：

> 实际上我的需求就是评价当前数据对于当前的 consumer 作为“训练数据”的价值是啥。

请围绕这句话重新审视问题。我们希望知道：

**在当前任务、Consumer 和训练条件下，一份真实或经准备/增强的历史训练材料，是否帮助模型学到对目标任务有用的东西？相对另一份材料，它增加或损害了多少价值？什么反馈足以让 Agent 据此改进数据处理，而不是被偶然分数误导？**

当前争论已经从“Source 为什么保守”“Specific 怎样匹配”走到了更基础的一层：给 Slow 的分数究竟在估计什么，它与训练材料价值之间是什么关系。

请不要预设答案是增加 seed、增加时间块、换稳健指标、聚类、Data Shapley 或影响函数。它们都是候选，须说明分别解决什么问题、不能解决什么问题。也不要把本任务改成“找一个更准的预测器”或“证明 LLM 没必要”。

本任务允许得出以下类型的结论：现有评价对象定义不合适；训练随机性是主要限制；目标分布/时间范围未定义；单位归因有误；确有低成本估值路线；或在现有合法信息与预算下，某种价值无法可靠识别。请给出依据和可执行下一步。

## 2. 项目与当前实验的必要背景

### 2.1 保留的研究目标与几何

项目为 SelfEvolvingHarnessTS。最终目标是用真实任务反馈改进 Agent 的 Harness，再帮助它处理后续任务中的数据问题。

- Fast 根据每条序列的合法 Context 和 General/Specific Skill 生成数据处理 Workflow。
- 一个候选内，不同实体可以采用不同 Workflow；**所有产生的训练材料必须汇入同一个共享 Consumer 拟合**。
- Slow 在批次边界读取合法实验反馈，修改可复用知识。跨任务原始 Episode 不直接进入 Fast。
- A3：公共 H0 起步，利用当前 Target 的合法反馈适应。
- A5：合法 Source 经验形成的知识起步，再以与 A3 相同的 Target 反馈权限和预算适应。
- F：Harness 冻结，但允许当前任务内的搜索。它不等于 A3。
- 公共评价器、指标、Consumer 和训练协议是实验仪器，其改进不算 Harness 学会了什么。

**某评价实体的预测损失下降，不等于“修改该实体的训练数据”造成了这个下降。** 共享模型使训练干预可以影响全部评价实体。不可从多个模型的逐实体成绩中拼出一个虚构的联合训练方案。

以下是当前小型增强线的事实，不是整个项目永远不可改变的参数：

“优于 naive”只能说明超过那几个基线，不能单凭此事排除 Consumer 欠调、训练不足或配置依赖。允许审查这些问题，但请与数据估值问题分开。

### 2.3 当前反馈和控制权

最近的 Harness pilot 使用：

- C_A：两处合法校准 origin，Agent/Slow能看到并据此研究或更新。
- C_B：另两处校准 origin，原程序在所有 Agent 调用结束后取候选宏损失最小者交付；**Slow不能读C_B，也不能直接改这个argmin**。
- E：四处后续 origin，原课程冻结后统一评分，不回流本轮学习。
- 本任务引用的这些历史 E 已曝光，只能作开发诊断。

Source 已经能真实形成、匹配、加载并改变行为。其较可信内容是“统一 Time Mixup 在一些历史作业有效”；尚未证明它学会了什么条件适用、如何调查，或比固定增强/同预算搜索更好。当前主要问题不再是 Source 没送到。

有些旧卡把未测试的动作写成禁令；改形成提示可纠正建议强度，却未证明交付效用提高。因此，本任务不再单独研究“怎样把 Source 写得更好”，而是研究什么数据价值证据能够支撑这种知识。

## 4. 必须先澄清：我们究竟要估计哪一种价值

请给出简明 formulation，并用一个具体的32实体共享训练例子解释，避免只有公式。

至少区分：

| 对象 | 真正回答的问题 |
|---|---|
| 一个已训练模型在某个评价块的损失 | 这次实际模型在这个块表现怎样？ |
| 固定训练材料对训练过程的期望价值 | 以当前学习算法反复训练，这份材料平均带来怎样的目标风险？ |
| 一个训练单元/一组材料的边际价值 | 在明确的其余训练背景中，加入、删除、替换或重加权它造成什么变化？ |
| 一个准备/增强Workflow的价值 | 这个变换生成的材料，相对原始或另一配方是否改善训练结果？ |
| 一条Skill/Harness的价值 | 它是否在后续作业中帮助取得、构造或利用更有价值的训练材料？ |

以下仅是供你批判的起点：

令训练过程为 f=A(D;ω)，其中A包括架构、初始化方式、优化器、训练预算、归一化和必要的模型选择规则；ω是声明了范围的随机性。D0为参照材料，Dπ为处理后的材料，Q为目标评价分布/工作负载：

\[
V(D_\pi;D_0,A,Q)=
\mathbb E_\omega\!\left[
R_Q(A(D_0;\omega))-R_Q(A(D_\pi;\omega))
\right].
\]

若只改变训练组g：

\[
\Delta_{g,a\to b\mid D_{-g}}
=
\mathbb E_\omega[
R_Q(A(D_{-g}\cup D_g^a;\omega))
-
R_Q(A(D_{-g}\cup D_g^b;\omega))
].
\]

请指出两式何时合适、还缺什么，或提出更恰当的定义。特别回答：

- “当前Consumer”究竟固定的是模型架构/训练程序，还是一个已训练参数状态？若是继续训练、fine-tune或只做一次梯度更新，定义如何不同？
- 如果当前权重完全冻结且没有训练/更新，这时讨论的是否已经不是训练数据价值？
- Q应是当前任务的哪些实体、哪些未来时间段、什么权重和损失？合法历史如何估计它？不知道未来Q时，哪些主张根本不能保证？
- 价值是相对谁的增量？None、Copy、既有背景训练集、最佳固定增强、空训练集回答的问题是否相同？
- 单元应是点、完整历史父对、父对子代家族、实体、时间块、联合配方还是作业？请推荐最小有用单位，不默认追求每个训练点一个分数。
- 背景、权重或其它实体配方改变后，原边际值是否还能用？平均多个coalition的价值与当前背景下的干预价值是不是同一个目标？
- 重复训练得到的期望与实际交付一个模型的效用如何衔接？不要用集成收益偷换训练材料价值。
- 材料让训练loss下降更快、在固定预算下泛化更好、充分训练后泛化更好，是三种什么价值？请区分学习效率、可拟合性与目标任务效用；不能用训练集loss更低直接证明材料质量更高。
- 我们不要求一种材料在每个未来窗口都获胜。请说明怎样评价其对明确目标工作负载的训练价值，而不过度要求不可保证的逐窗口赢家预测。

## 5. 核心调研与思考问题

### 5.1 怎样得到与目标任务对应的参照反馈

请比较固定校准块、多块时间评价、rolling-origin/backtesting、prequential评价、合法参考池或其它方案。

必须说明：每次训练在哪截止、donor/scaler能读到哪、何时获得校准标签、何时允许Slow更新、最终E是什么。区分：

- 同一个已训练模型在更多时间块评分；
- 不同历史截止点重新构造材料并训练；
- 新任务/新训练材料上的复用。

如果在当前训练段内部做历史回测，不能拿“使用了该回测未来的完整T训练模型”去回测过去；对应训练材料、scaler和donor都要按当时截止重建。有重叠滑窗、共享实体或相邻时间依赖时，解释什么单位可用来估计不确定性。

不要假定“更近”“更多”“平均”天然更接近目标Q。若需要平稳、可观测漂移或密度比等假设，请说明本项目是否有证据满足，以及失效时怎么办。

### 5.2 整体干预与局部归因如何衔接

请比较真实配对重训、局部替换/移除、组级对照、重加权、交互项和信用分配方法。

关键是：我们能否先可靠比较完整训练材料，再在必要时回答“是哪部分处理造成差异”，而不是一上来给13,856个重叠训练对逐个估值？

请用“32个实体共训一个MLP，只改变其中一组，其余材料固定”的例子，明确哪些结果能归因给这个组的干预，哪些不能归因到组内某个点，更不能误读为其自身预测损失。

如果估值依赖训练背景，请说明何时需要重新查询，而不是把一次价值永久写到某条序列或Skill上。

### 5.3 低成本代理到底能否帮助当前Consumer

请调研能估计训练贡献的梯度、影响、训练轨迹、可学习性或数据估值方法，回答：

- 它估计的是loss、局部参数变化、数据归因、候选排序还是有限幅度干预后的真实效用？
- 依赖哪些checkpoint、梯度、Hessian近似、参考标签或额外模型？是否适配当前非凸小MLP、联合X/y增强与固定步数训练？
- 删除样本、改变权重、增加合成对、非线性替换训练材料之间，近似能否直接通用？
- 当动作改变多个实体或两步增强时，线性近似和可加假设何时失效？
- 如何用少量真实共享重训验证代理，包括符号、排序、选错后的损失和开销？只展示相关系数不够。
- 用什么参照评估“估值是否准确”？若使用更高预算的配对重训作为近似参照，须预定目标范围并报告参照本身的不确定性；不得拿一次有噪声的E、后见最佳候选或同一份被优化的校准分数冒充绝对真值。
- 能否用代理减少昂贵实验，或给Slow提供更有区分力的假设，而不替代最终真实消费者效用？

**必须包含“直接真实重训是否已经足够便宜”的竞争解释。** 当前小MLP几十秒量级一次；不能默认近似归因必定比它划算。

### 5.4 哪些不稳定应消除，哪些是价值本身有条件

请分开训练随机性、增强随机性、评价有限样本、实体/时间共同冲击、真实数据分布变化、训练背景交互、候选搜索的选择偏差。

请回答配对随机数、重复训练、块级重采样、分层估计/收缩、序贯预算分配等分别针对哪一项，前提是什么。

对H3类和a94类给出不同的解释路径。不要用“高噪声”统称所有反号，也不要用当前两对候选拟合一个必胜诊断规则。

### 5.5 什么目标才符合“有价值”和“优化大部分数据”

请讨论当前宏NMSE、原始MAE、典型实体表现、最差群体/极端事件风险各回答什么问题。

- 多数实体改善与宏期望损失改善可能不同，应由目标决定，不能事后切换。
- 去掉极值可能降低估计方差，也可能删除真正关心的风险。
- 当前训练尺度归一化是否放大某些实体？如何将尺度影响与MSE平方损失的影响分开？
- 若推荐修改指标或聚合对象，说明它改变了什么任务目标；保留旧结果，另定未来协议。
- 公平控制样本质量权重、有效正则、训练步数和搜索预算；公平条件下的正则化收益本身可以是数据增强价值，不必人为排除。

### 5.6 训练价值证据怎样成为Slow可使用的经验

请提出一个最小反馈示例，至少说清：

“比较了哪两份材料／改了什么 → 其余训练背景 → 当前Consumer与目标范围 → 实际证据与不确定性 → 目前能支持/不能支持什么 → 下一项合法观察或实验”。

另给两段假设性例子，显著标为示意：
1. 有足够证据保留一种处理的局部优先级。
2. 表面负分不足以否决处理，应怎样安排下一项有区分力的实验。

不要求一律产生复杂Skill；有依据的默认做法也可以有用。但要区分“默认有效”“条件有效”“尚未测试”和“有反证”，避免把不确定转成identity或禁令。

若提聚类，请区分按数据可见特征分组、按干预响应分组、按Agent共同过程失误分组。说明它解决估计、异质性还是Harness归因；避免用未来响应标签直接定义部署时的Scope。

最后解释：公共评价器的能力与Agent学会怎样选择实验，是两个怎样拆开的贡献？未来怎样用同预算F/A3/A5及简单估值/搜索基线验证？
