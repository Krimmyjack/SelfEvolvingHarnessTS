# SA-1 设计稿:Skill 作为可更新假设(修订循环)

状态:主线定稿,呈 sol 裁定。2026-08-28 03:3x。
事实基础:`artifacts/functional/e2/sa0_wiring_audit.json/.md`(SA-0 只读接线审计,rev 9894a5d 工作树;所有 file:line 判定以其为准,本稿不重复引证细节)。
定位:用户论题——"Skill 由经验初始化(天然适应于特定数据、天然窄),再由后续 Gain/Harm 持续修订;它是可学习组件,不是一次成型的规则"——的机制化。阶梯修订案 v2(供给档证据价 2→1)解决"经验早入场";本稿解决"入场后随反馈变好"。两者合起来才是完整的安全论证:低价入场之所以可接受,是因为错误可被事后修正;事后修正之所以有素材,是因为经验早入场。

## 0. 一句话主张

把 Skill 从"编译一次即冻结的规则"改为"带证据账本、可版本化收窄的假设":正向反馈累计证据,冲突反馈机械收窄 Scope,害证触发限制;收窄自主、扩权定价;每次修订可审计、可回滚。

## 1. 现状与目标(字段级)

审计已证:今天的卡在产线可达的一切分支里**零写回**——正向不累计(转化只新铸 Target-local 卡)、Support 拒不可见、delayed 拒经由本 harness 不调用的路径;`revision` 是静态著作字段;撤权网对供给卡未上膛。

| 组件 | 现状 | SA-1 目标 | 依托 |
|---|---|---|---|
| Program | 编译时冻结 | 不变(修订不改动作本体) | — |
| Scope (`observable_applicability`) | 编译时冻结,无写者 | 可被 PATCH **单调收窄**(追加 `not(排除条件)`) | PATCH 面已授权(harness_surfaces.json:65-77),AST 已支持 not,缺的只是写者与故障因授权(Q1) |
| 证据账本 | evidence 块编译时冻结,永不追加 | 逐单元结果 append-only 追加(来源/双门结果/收益) | `risk_guards` PATCH(SHA 前置)已有先例 |
| 风险注记 | 自由文本(C40 教训) | 结构化(几何注记/分域限制),禁自由文本 | 既有结构化 guard 词汇 |
| 权限档 | 阶梯 v2 | 不变;修订机制**不得**改档 | 红线,见 §3 |
| 版本 | `revision` 无人自增;快照层内容寻址+血缘完备 | **内容 sha 版本 + 快照血缘**,不动 `revision` 字段(零铸卡点改动);`set_active(旧 sha)` 即回滚 | store.py 现役(Q2 的主线倾向) |

## 2. 修订规则(按反馈类型,全部结构化编译,禁自由文本)

触发者与执行者都是 Slow(边界处),输入只有已记录的机器字段;每条修订自动产生:一条修订 Episode(谁、依据哪个单元的哪条反馈、改了什么)、新内容 sha、快照血缘记录。

**R1 正向**(供给候选在 Scope 匹配单元经双门转化):证据账本追加一行。**不升档、不扩 Scope**——供给转化系受引导,按既有 UNGUIDED 规则计零;升档仍须未引导证据(红线,防 C40 式自我授权循环)。

**R2 冲突**(Scope 匹配、供给候选被 Support 拒于材料线之下,或 delayed 判 CONFLICT):从**拒绝单元**的 `fast_features_binned`(已在账,审计 A-1)机械编译排除条件——取拒绝单元与支持 Episode 取值相异的轴,构造 `not(all(相异叶))`,PATCH 到 `observable_applicability`。约束三条:(a) 排除叶**只许取特征契约保证存在的轴**(规避三值逻辑缺叶弃权造成的静默过度排除,Q8);(b) 一次拒绝只编译一次有界 PATCH,**只许由实拒单元编译,禁预测性排除**(Q12 的有界损失条款:少赚可以事后用新证据赎回,误伤不能);(c) 排除不得引用 dataset 名(照旧)。

**R3 负向/害**(delayed NEGATIVE,或任何 harm 事件):同 R2 排除之外,追加结构化风险注记;harm 事件直接触发**分域限制**——即把现有 `restricted_by_target_feedback` 语义装上"作用于该 pattern 域"的变体,并把写端触发扩到供给卡(为 Q4 上膛)。主线倾向 Q3 的答案是"分域限制 = 换名的 Scope 排除 + 风险注记",两机制合一,不新增 guard 键。

**R4 verifier 拒**(几何不合法):只加几何注记,**不动 Scope**——几何失配不是 Scope 的错,收窄 Scope 掩盖的是 Program 几何问题(ECG200 教训:同 family 不同几何命运)。

## 3. 治理红线

1. **单调收窄 Slow 自主**:Scope 缩小、降优先级、排除、限制,不需要新证据许可(方向上只会少供不多供)。
2. **任何扩张按阶梯定价**:扩 Scope、升档、解除限制,一律回到阶梯 v2 的证据价(未引导正例),修订机制不得夹带。被收窄的卡想赎回被排除的域,价格 = 该域的一条新未引导正例。
3. **版本化可回滚**:内容 sha + 快照血缘(现役);修订动作本身入 Episode 账,可审计。
4. **Episode 证据链 append-only**:审计 Q5 证实当前内存账本的 delayed 覆盖会丢"仅 Support"版本;卡的证据账本必须以追加行实现,不依赖内存账本槽位。
5. **当前 Target 主权不变**:一切修订只改"卡在哪里被供给",不改双门、不改 harm 否决、不改部署规则。

## 4. 前置仪器(SA-1 Part 0,纯增字段,先行落地)

审计 A-1 列明的四个归因缺口,全部是**加字段零行为改动**(Q6 主线定性:仪器非机制):

## 5. SA-1 实验设计(机制考,development 级)

**目标**:证明"会修订的 A5-adaptive"优于"拿同一 v0 但永不修订的 K0-fixed"——修订发生后,少浪费、不重复挨拒、收益不丢、harm 不增。

**v0 种子**:双证据卡(GPA+GPMvF 既有 Episode,交集 Scope),provenance 如实标 development seeded。理由:审计跨项发现三——n=1 退化交集窄到 1/5 匹配,"没有东西可修订";修订考需要一张**够宽到会犯错**的卡。n=1 卡的初始宽度问题走 Q9(阶梯定价问题),与本考分离。

**课程骨架**(复用已审计单元,冻结后不许换):
1. 冲突单元前置(PowerCons-impulse:Support 实测贴线 0/2,天然拒绝场)→ 预期触发 R2 收窄;
2. 正向单元(GPOvY:5× 余量)→ 预期收窄后仍供给、仍转化(收窄没有误伤);
3. 第二个同贴线型单元 → 预期 A5-adaptive 的排除生效不再供给(省 probe、零挨拒),K0-fixed 继续供给继续被拒;
4. identity 单元 → 双臂都不该部署(安全面)。

**四臂**:Static / A3-reset / K0-fixed(v0 冻结)/ A5-adaptive(同 v0 + R1-R4)。

**主读数**:修订后单元上的 probe 浪费差、重复挨拒次数差、regret 非劣、harm 恒零;卡版本链(v0→v1)与逐版本账本作为机制证据。

**可证伪预测**:(1) PowerCons 拒绝后 A5-adaptive 产出恰一次收窄 PATCH(v1);(2) v1 在 GPOvY 仍匹配仍转化;(3) 第三单元 A5-adaptive 零供给、K0-fixed 继续供给且再被拒;(4) A5-adaptive 对 K0-fixed 的 probe 总量差 ≥1 且 regret 差 ≥0;(5) 四臂 harm 全零。

**预算**:LLM ≤150 / fit ≤300 / 墙钟 ≤4h。**止损**:拒绝发生而收窄 PATCH 未产出 → 单一 first-fault(触发接线)收口,禁改课禁调门;两跑同向才许复合措辞。
