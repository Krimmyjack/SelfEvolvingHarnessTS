## 3. 公共反馈与分析的边界

make_feedback 仅接受已经依法可见的 c_a 或 c_b；拒绝 e。输出：
- 对象、比较方向、校准块、种子数；
- 候选平均 NMSE、各 seed 的配对差、样本 SD/范围与方向计数；
- 各 origin 差异、各实体贡献及绝对差占比；
- 证据范围和未确定项。

接口允许 c_b 不授予当前 Slow 读取 c_b 的权限。本包不接入原课程；如果后续让 Slow 适应 c_b，需统一修改未来协议的信息角色。当前 Source/选择器均不修改。

E 只用于独立的回顾分析，不进入 feedback_packets.json；全部数据已曝光，不称新数据或密封验证。增添重复本身不计为知识增量。

## 4. 固定验收问题

1. 旧三次与新三次在同一 C_B 的平均方向是否一致？报告原值，不只报一致/不一致。
2. 新三次内部的配对差是否仍大幅波动或换号？检查 leave-one-seed-out 的描述性敏感性，不将这些子集当独立重复。
3. 新重复组的 C_B/E 方向是否一致？若仍不一致，训练重复未单独解决该对候选的时间迁移问题。
4. 小差异是否仍不能稳妥分辨？不以强制选赢家、删实体或调阈值制造“稳定”。
5. 公共反馈是否明确保留上述不确定性且不泄漏 E？

三次平均的方差较小可以来自平均本身，不能单独作为有效判据；重点是独立重复组和后续块上的实际对照。仅两对候选，不推断整个系统或未来误差率。
