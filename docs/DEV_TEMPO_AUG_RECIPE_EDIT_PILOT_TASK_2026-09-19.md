## 1. 本包要回答什么

主假设：P_NoMixRecipe 的优势可能部分来自每窗口随机组合的生成方式；保持该生成方式，只关闭少量组件，可能构造出比原配方更好的训练材料。Fast 能否根据当前合法观察与反馈找到并交付这种改进，由实验检验。

三个问题分别计分：
1. 原配方是否存在可改进的组件？固定七份单组件消融提供受控开发读数。
2. Fast 构造并交付的局部修改是否胜过原配方和同预算随机局部修改？
3. 若更好的材料已被该臂评估但未交付，构造收益与选择损失分别是多少？

这是 Program 构造能力的小规模实验，不是 Slow/Skill 有效性或完整 A5 验收。不修改反馈块，不改 Consumer，不重新讨论哪个模型更好。没有“无卡 Fast 先获胜才允许研究 Skill”的永久门槛；本包只检验一个具体的新构造能力。

## 3. 唯一新增的构造能力：配方组件开关

新增 opt-in typed program，示意：

~~~json
{"op":"P_NoMixRecipe_Edit","disabled_ops":["tp_random_conv"]}
~~~

disabled_ops 只允许原七个 tp_* 原语的名称，去重后按原 PRIMITIVES 顺序规范化，长度 0、1 或 2。参数强度、类别抽样权重、两类抽取数量、内部类别二选一概率、卷积原概率、执行顺序均不可编辑。长度 0 与原 P_NoMixRecipe 是语义别名，不产生新候选或独立拟合。

执行语义是“先按原配方抽取，再跳过被关闭的原语”，不是从剩余原语重新抽取：
- 例如关闭 tp_shock，原来抽到 shock 的窗口跳过这一操作；不会自动换成 regime。
- 关闭 tp_random_conv，原来抽到卷积的窗口跳过；其余抽样不变。
- 不为保持两步强行补一个操作，不重新归一化类别权重，不加入最小改动过滤。
- 可能只剩一个操作，或某些窗口成为 identity；如实记录，不当故障或无效候选拒绝。

一共 29 个局部程序：原版1 + 单关闭7 + 双关闭21。完整计划仍可有 default 与最多8条原有合法 T 谓词规则，对不同实体赋不同开关；UNKNOWN 不触发。共享模型始终在全批材料上训练，不能拼接多个模型的逐实体预测。

本包 Fast/Random 的“新材料”限制为上述配方局部编辑；公共参照仍可直接提交。这是本包研究对象的边界，不是关于旧显式组合无用、禁止分组或禁止三步的 Skill 规则。仓库原显式算子接口保留，不全局缩小未来 Fast 权限。每个新宏程序独立使用，不能再在宏外追加算子。

窗口内的输入和训练目标联合变换，最终评价真值不变。指导文档必须说清子训练目标也改变，不能写成“只增强输入”。

## 4. 随机性：不能把关闭组件变成重新抽整份材料

原版 v2 使用 entity_program_seed(job_index,52,entity_index) 为 NoMix 配方生成随机流。所有 Edit 以同一 NoMix 父流为基础，开关不能参与该父流 seed；训练 seed 与材料随机性仍分离。

原配方的类别、原语和卷积选择与原语内部抽样交错，直接跳过一次函数调用会挪动后续随机流。因此必须隔离“父配方抽样”和“被编辑材料执行”：

- 可逐窗口运行原配方的 shadow 路径，临时保存各操作入口的三种 RNG 状态、操作名和原抽样执行顺序；用这些状态在编辑路径上重放保留操作。
- shadow 路径始终使用原版材料推进，决定后续窗口抽样；被编辑路径不改变 shadow 的后续随机状态。
- 不持久化全量 RNG 快照平台，逐窗口临时释放即可。记录开关、父 seed、构造时间和必要的小型验证例即可。
- 保留操作的随机抽取应对齐，但输入变化导致的 std/均值/值域变化仍按源函数重算，不能把中间张量复制过来冒充重新组合。各组件有交互，消融差不是可加总的独立贡献。
- disabled_ops=[] 必须与现役 v2 原配方材料逐位一致；同一 Job/实体/开关不受分支、方案名称、构造顺序影响。未修改实体的子材料与原配方逐位一致。

实现可采用其他等价方式，但以上语义必须成立。仅同一个数值 seed 不足以通过这项核对；不得用哈希代替数组/抽样语义比较。

原29个局部程序的稳定编号只用于枚举/缓存，不改变旧53程序编号。沿用 JSON 语义键，增加局部 profile 与开关，禁止与旧预设错误命中。不新增 SHA。

## 8. 读数：三个层次，不能用oracle充当交付

主终点为既有 normalized_mse_macro 的E，保留全部实体与起点，不去掉极端值。

统一收益：
Delta_j(A,B)=100*(mean_s E_j(A)-mean_s E_j(B))/mean_s E_j(None)。
正值表示B更好，单位是相对该Job的None均值的百分点；不是相对A的提升百分比。

主表：
1. F_edit相对原NoMix、Random_edit_B4、Menu_CA、None及其余公共参照的逐Job/等权差、胜平负、最大伤害、逻辑评估与实际成本；明确commit是新编辑还是公共参照。
2. 七消融分别相对原NoMix的C_A/C_B/E配对差，材料X/y改动量、实际触发率；只能称“这一组件在完整配方背景下的移除效应”，不能称独立可加总贡献。
3. 各研究臂自身已评估池的E最优、实际commit、E排名与遗憾；不得用跨臂合并最优冒充Fast曾经拥有。

可作精确描述分解：
- 候选池可用收益（包含公共参照）= E(NoMix)-min_{m in own pool} E(m)。
- 选择损失 = E(commit)-min_{m in own pool} E(m)。
- 实际净收益 = 候选池可用收益-选择损失。
都以三seed均值及统一分母计算。own pool只含公共参照与该臂真实评估项。另外计算“公共池最优E - 加入该臂新编辑后的池最优E”，区分公共供给与新编辑增加的机会；无新编辑时该项为0。全池oracle与获胜消融有事后选择偏差，只作诊断，不证明可部署收益。

加报一个0额外拟合的影子选择：同一Fast池按C_A argmin会提交什么、其E怎样。不能回写真实commit。这可区分候选供应差异与Fast最终判断差异。

逐Job用同一分母构造三seed配对向量，SE和t95(df=2, t=4.30265)同向量计算；不能把2SE当n=3的95%区间。四Job为时间重复单位，报告等权均值、逐origin和留一Job范围，不把12个seed×Job当12个独立任务。七消融的最优者不以未经多重比较考虑的单项区间宣称显著发现。

所有结论限于当前固定增强随机实现与3个Consumer seed；没有重抽增强随机种子，不能声称已覆盖材料生成随机性。
