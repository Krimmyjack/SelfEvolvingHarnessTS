## 7. 表格与摘要需要的读数

主指标沿用：
G(A,B) = 100 × [mean_seed E(B) − mean_seed E(A)] / mean_seed E(None)。

报告各域及三域等权的 normalized MSE、相对 None 的收益、与各主要对照的成对差；沿用父包按时期和实体组聚类的 95% 区间。不把 pp of None 写成相对无卡的误差下降百分比。可直接从既有预测补 MSE / MAE，不为次要指标重训。

成本表分清：历史筛选与学习的一次性成本、新案例的 Agent 决策成本、每个 Consumer 的训练成本、AutoDA 的特征与策略联合训练成本。比较整套系统总成本；不能将 AutoDA 的训练全计费，却漏掉我们交付后的 Consumer 训练。

中间证据只复用轨迹：交付程序分布、构造/检查次数、token、交付是否改变。挑一例典型收益和一例失败解释机制；不新增质量代理指标竞赛。
