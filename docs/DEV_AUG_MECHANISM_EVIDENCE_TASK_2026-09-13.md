## 3. 第一部分：把“同小时更相似”拆成具体事实

主分析 R 与 U；P/S 的材料由 R/U 组成，不需要把相同材料重复计算。

沿真实 Consumer 输入坐标，按作业、实体和父对计算，保留实体内分布及作业汇总：

1. donor 时间距离、同小时比例、X 与 y 的实际时间重叠比例。
2. 父与 donor 的 X RMS 距离、y RMS 距离；子对相对父对的 X/y 改变量分开报告。
3. X 的水平差、标准差差异，以及逐 24 点块均值构成的轮廓差。以上只做描述，不建立新的条件阈值。

**不要只报平均改动点数或子样本数量。** 回答具体是 X、y、局部水平还是形状发生了什么变化。

## 4. 第二部分：检查重复程度与输入—目标相容性

用固定、透明的近邻描述，不训练估值器，也不搜索最佳距离或 k。

对同实体的每个父对 i 及其冻结 donor j：

- 参考集只包含该实体的真实父对 l，要求 `abs(l-i) >= 48` 且 `abs(l-j) >= 48`，避免参考目标与父/donor 的历史目标直接重叠。
- 上述排除仍可能保留 X 重叠，必须报告，不能称为独立参考集。
- 对父输入、donor 输入和子输入，在同一个参考集中按冻结 scaler 坐标的 X RMS 距离找 5 个近邻；只用 X 找近邻。
- 记录最近距离、5 邻居平均距离，以及对应 y 与这 5 个近邻 y 均值的 RMS 距离。
- 子输入与父输入在同一参考集上比较。R/U 的参考集可能不同，报告候选数；直接 R/U 对比再用排除二者 donor 目标重叠后的共同参考集计算一次，避免把参考集差异当机制。
- 参考不足 5 个或数值无效记 UNKNOWN，不临时换 k、补 donor 或放宽排除条件。

要求输出两类读数：

**覆盖描述**：U 子输入是否比 R 更接近真实输入集合？这种接近相对原始父对本来已有的近邻距离有多大？

**关系描述**：子输入落在某个真实输入邻域时，其历史目标是否比父对更偏离该邻域目标？这种变化是否伴随父/donor 的水平或轮廓差异？

必须同时保留反例：距离变小但目标偏离变大、距离变大但目标偏离不大等。不要仅挑符合故事的例子。

这是一个固定描述器。近邻历史目标并非真值裁判；差异可能来自真实多解、相位偏差、距离不合适或稀疏覆盖。不能据此宣告合成标签错误、样本无价值或阈值已学会。

计算按实体分块，避免一次创建全池两两距离矩阵。可用 NumPy 的矩阵运算；不建索引平台。

## 5. 第三部分：现有 Consumer 对混合约束如何响应

只加载该包 N（无增强）的已有模型，3 作业 × 4 seed；不重新训练、不微调、不做梯度更新。各 seed 使用自己的冻结 N 模型，不能挑效果最好的 seed。

令 f 为该模型，权重 w=0.25，子对满足：

`x_mix = 0.75*x_i + 0.25*x_j`

`y_mix = 0.75*y_i + 0.25*y_j`。

计算：

- **响应非线性量**：`RMS(f(x_mix) - 0.75*f(x_i) - 0.25*f(x_j))`。
- **固定模型的训练约束变化**：分别报告父对、donor、子对的目标 MSE，以及原始+子对各半权重相对只使用原始对的损失变化。
- 将上述结果与第二部分的描述放在一起，保留按实体及种子的分布。

这些数说明“现有模型在哪里不满足混合训练约束”，不说明约束值得满足。更大的残差可能对应有用正则化，也可能对应不合适目标。它们也不是影响函数、训练数据因果贡献或新的价值分。
