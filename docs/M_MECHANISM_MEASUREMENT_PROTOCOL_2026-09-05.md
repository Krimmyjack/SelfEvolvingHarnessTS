## 2. 主线独立补充(r2 修订后)

### 2a. 结构化异质性应在 Task × Consumer × Pattern 三轴上找;但库内现有证据只是"设置不同",匹配比较才能归因

项目前提预测的是三条结构轴上由机制决定的效应差异。HEC-1 / D1 / v2 全在单 Task × 单 Consumer × 单集里找逐序列异质性
(前提不作预测、结构最弱、又被 pooled 路由混杂的一层)。库内已有:KDD Forecast 正(best-fixed +0.2629;2856 双面 +0.29~+0.65)、
Yahoo AD 12/12 程序级宏效用为负(`INVERTED_EFFECT_OBSERVED`)、P4d 缺口依赖 / 组合必要 / 顺序效应。
**按 astra ①,这些只证明"设置不同则结果不同"**;归因需要匹配比较,已加入 M0:
(i) **同数据的任务—Consumer 设置比较**——在 Yahoo-24 曝光序列上以 Ridge 跑 Forecast,与同序列的 AD/IForest 读数并列(同时改变了 Consumer 与评价目标,**不称 Task 匹配**;astra 修正);
(ii) **同任务换数据**——在 KDD 与 NOAA(均为曝光 development 预测集)上验同一条 Pattern 规律(缺口层 × 程序)是否同向;
(iii) **同数据同任务换 Consumer**——KDD 上 Ridge-pooled / per-channel / TSFM(M0 原有)。
Forecast 承担主要能力验证;AD 只承担"系统是否避免错误清洗"的条件化检查,不作为进化课程的格(astra 优先级一)。

### 2b. 决策粒度由三足迹推导,不由 Consumer 名称决定

| Consumer | 训练干预影响谁 | 服务决策作用于谁 | 证据在哪层有效 | 合法的 Skill 决策粒度 |
| --- | --- | --- | --- | --- |
| Ridge-pooled | 全 roster(经共享模型广播) | 逐序列(context / route) | 逐序列 outcome,但训练侧混杂 | 训练准备 = **数据集级**;**serving-context = 序列级**(D5:严重伤害中 context 为最负分量 2/10;context-only 逐序列增益中位 ≈ +0.1——**0.255 是严重伤害样本内的分解份额,不是总体收益份额**);route 逐序列但与训练混杂 → **不作逐序列 Skill 决策** |
| Ridge-per-channel | 仅该序列 | 该序列 | 逐序列,无跨序列干扰,仍含 raw/program 模型选择效应 | 序列级(准备 + 模型选择合一) |
| TSFM 冻结 | 无训练侧 | 该序列的 context | 逐序列,纯 context 效应 | 序列级(仅 context) |
| IForest 逐序列 | 该序列 | 该序列 | 逐序列 | 序列级 |

P4 的 +0.2629 是 pooled 下训练准备这一足迹上的合法数据集级正结果;pooled 下 **serving-context 逐序列决策**是被忽略的合法序列级面
(收益小但尾部轻),M0 单列一格。

### 2c. 臂设计:把适应与进化分开计量;分歧是结果不是手段

闭环阶段臂(astra 修正,执行计划 §4.1):**A**(局部适应照常、结构冻结)/ **B**(相同局部适应 + LLM 结构修订)/ **C**(相同局部适应 + 同预算确定性结构提议)+ Static 参照。
读数:结构修订价值 = B − A;LLM 提议额外价值 = B − C;确定性修订价值 = C − A;历史积累 = A5 − A3(扩展阶段,并报 Static)。第一臂**不用** A5-frozen(关闭局部适应会把适应与修订两种贡献混在一个差里)。
**行为分歧数、完整决策数、修订可达性是实测主读数;不得为达到分歧数改动作**(astra ③)。

### M1 · 可学习性:跨窗持续性 = 胜过无历史基线的增量(astra ④)

## 4. 方法骨架(候选,不冻结;测量后按 §3.7 裁剪)

三个对象(astra):**可迁移的行为假设**(某类可观察情境下什么 Workflow 值得尝试、可能在哪失败)/ **当前目标上的验证证据**
(历史经验在新数据上是否仍适用、可获多大执行范围)/ **可复用的结构修订**(反例后 Agent 修改 Workflow 或适用条件,经独立验证成为下一版)。
自进化贡献落在第三个对象及其对下一数据集的帮助;统计模型只服务第二个。

```
Skill(可迁移,不含 UID、数据集名)= Workflow(typed, ≤2 步)+ 适用性假设(预声明层谓词 + 已知失败情境)+ 版本谱系
适用性证据(目标本地)= 逐格序贯证据(LCB > 0.005 ∧ P(Δ < −0.30) < δ)+ anytime-valid 区间(治窥视)+ 衰减(治漂移,M1 校准)
决策策略 = 探针 / 弃疗 / 部署;未见格只探针
唯一结构编辑面(先选一个;astra 优先级二)=
   默认候选 **Workflow 组合**(算子序列 / 参数):P4d 已示组合与顺序效应真实;§2d 主导失败模式(FLAGGED)的匹配面正是它
   备选 **适用条件**(Scope 子句):仅当 M3 判 PATTERN_INFORMATIVE
   → 由 M 决定,只开一个;新特征 / 分组 / 遗忘策略 / 实体后验一律不进核心,除非回答"去掉它,哪个已测量能力就无法实现"
Slow(LLM)= 从失败普查提出该编辑面上的修订(内容必须由 Agent 从反馈提出);确定性提议者同预算对照
生命周期 = v1.1 不变(Draft / 独立验证 / Active / 撤销 / 修订 → 重遇);Skill 粒度按 §2b 三足迹进 Consumer 契约
```

## 5. 最小闭环阶段(方法裁剪后的第一段 live;先于任何多臂曲线)

- **目标(唯一)**:在自然数据纵向切片上得到 ≥1 条完整修订链:
  `反馈冲突(已 Active 的 Skill 在后续单元受伤)→ Agent 在唯一编辑面上提出修订 → 独立单元验证通过 → 后续同类情境改善,且优于冻结的祖先版本`;
  **重复性**:同一链在 ≥2 条预注册顺序中重现,或 ≥2 条独立链。
- **臂(最小)**:A-frozen / A-evolve / 确定性提议者;语义预算(每格 ≥1 完整决策、≤2、物理顶 10)。
- **主读数**:修订可达性(进入可修订状态的次数 / 实际提出 / 通过验证 / 重遇改善)、行为分歧数、完整决策数、伤害与覆盖;
  这些是**结果**,不得为其改动作(astra ③)。
- **AD 条件化检查面**(一次性):把 Forecast 终态 Skill 交给 AD/Yahoo-24 格,读"是否弃疗 / 是否避免错误清洗";不进课程。
- **接线验收**:先在 M4 种植副本上要求环路学回规则,再跑自然切片。
- **闭环成立后**才进入 §6。
