# DEV-AUG-DONOR-PATTERN-PROBE：共享训练下的 donor 规则与 Pattern 分组可辨性

日期：2026-09-13。主执行者：Opus。性质：零实验 LLM 的有界开发诊断，非 Skill 学习实验。

本文件是供用户分发的执行规格；任务书写成不代表实验已启动。执行者收到用户转发的“按本任务书执行”后，在下述边界内连续完成，不逐笔请求普通实现确认。

## 0. 本轮只回答什么

主问题：一个预先定义的可见 Pattern 分组，在相同训练背景中应用同小时 donor 规则，相比同数量的随机分组，是否产生可分辨的整体训练价值差异？

同时回答：统一 donor 规则是否影响当前 Consumer；条件方案是否比现有随机 donor 及统一替代规则更有用。

固定研究假设：
- 日滞后相关在历史前后两半段均较高且相近的实体，可能更适合与相同钟表小时的历史窗口混合。
- 这是研究者提出的操作性假设，不是已验证的周期机制，不是 Agent 学到的 Skill。
- “同小时”指日历上的同一小时，不等于已经识别到相同的真实周期相位。
- 分组有效、无效、信息不足均可收口。不得为了正号改变 Pattern、阈值、规则、种子或作业。

本轮不恢复 Source/A3/A5，不实现新的观察平台、路由学习器或 Skill 格式，不修改交付规则。完整模型层面的受控比较是本轮证据单位。

## 1. 不可混淆的四条原则

1. 每个完整方案把全部32个实体的材料汇总，真实训练一个共享 MLP。异质方案必须重新共同拟合。
2. 禁止把不同统一模型的逐实体最低损失拼成“条件化 oracle”。该数不是本系统条件化训练的上界。
3. 单方案 seed 极差不能用作配对差的噪声门；局部效应不能按修改实体数/32线性推算。
4. 不确定不等于无效；有限候选没有可读增量，只限制本任务配置，不关闭整个 Pattern/Skill 方法。

旧实验、旧 family 判词和原协议保留。新包显式记录 donor 生成干预及共同训练几何，不撤销历史结果、不把旧范围扩大为新问题的否决门。

## 4. Consumer 与材料质量权重

原样使用现役共享MLP：
192→128→64→48，ReLU，AdamW，lr=1e−3，weight_decay=1e−4，2000次更新，每批64个父对；无新增架构、早停、超参数搜索或 ensemble。

所有增强臂：
- 对归一化后的完整父片段 z=[X;y] 做一次 TimeMixup：child=0.75*z+0.25*z[donor]。
- 每父对保留原始视图与一个子视图，损失权重各0.5，总质量权重与None一致。
- 不重新归一化派生对，不改预测侧输入，不改真实评价目标。
- donor始终为同实体的原始父对，不能来自派生样本。
- 不改变训练采样顺序或总更新次数。

## 5. 冻结的 Pattern：只用T，不训练分类器

对每个实体：
1. 以当前T的公共scaler归一化672点；分为前336点和后336点。
2. 每半段分别用带截距的一元OLS去除线性趋势，自变量为0…335。该去趋势只用于描述量，不改训练材料。
3. 对残差计算 Pearson corr(residual[:-24], residual[24:])，得到 r_head、r_tail。
4. 任一相关输入std < 1e−8、结果非有限时，记UNKNOWN，Pattern不命中。
5. 否则命中条件固定为：
   r_head >= 0.60 AND r_tail >= 0.60 AND abs(r_head−r_tail) <= 0.15。

0.60/0.15是本次预先指定的工程探针界值，不是已学到的阈值，也不是显著性门。不得按命中数或分数改界值，不添加第二种Pattern。

保存两个相关值、UNKNOWN原因、布尔命中和命中数k。名称使用“前后半段日滞后相关较强且相近”，不得把它直接宣布为“真实稳定周期类型”。

允许k=0或32：如实记SCOPE_DEGENERATE，并复用等价方案；不人为挑一半实体来制造异质性，不因此终止仍可解释的统一规则比较。

## 6. 两种 donor 原语

### R：原有随机错排

每实体独立使用 `np.random.RandomState(900090+i)`，i为冻结roster中的位置。
原样复用现役 `_derangement(433, rng)` 语义，不变成有放回采样。
保存完整433项索引，须与夜间包对应实体的原随机TimeMixup逐项一致。

### U：同钟表小时错排

同样为每实体新建 `np.random.RandomState(900090+i)`，与R及训练随机流相互独立。
- 按父窗口起点的实际钟表小时0…23，将433个父对划分为24组。
- 按小时升序、组内父索引升序遍历；对每组调用同一 `_derangement(len(group), rng)`，再映射回全池索引。
- 本数据每组应有18或19项；若出现组规模<2或时间不连续，记仪器/数据失败，不能用self donor补齐。
- 最终433项必须为全池的一一映射，donor != parent；每个原父对恰好充当一次donor。

两规则保持相同donor使用次数和混合权重。U可能同时改变时间距离、窗口重叠及波形差异，所以U−R只归因到“完整donor规则替换”，不能唯一归因为相位保护。

## 7. 五个完整共享训练方案

| 方案 | 全部32实体的材料 | 用途 |
|---|---|---|
| N | None，仅原始父对 | 原始材料锚点 |
| R | 全体使用随机错排TimeMixup | 当前强固定基线 |
| U | 全体使用同小时错排TimeMixup | 统一替代规则 |
| P | Pattern命中实体用U，其余用R | 真实条件化联合方案 |
| S | 与P相同数量的随机实体用U，其余用R | 排除“只要改k条就好”的解释 |

S分组：作业序号j=0/1/2，使用 `RandomState(2026091300+j).permutation(32)[:k]`。
不按分数或Pattern重叠程度重抽；恰与P相同也照实记录。只做一个预先固定的随机分组，不能据它声称优于所有随机分组。

关键执行要求：
- 每实体的R/U索引和子材料先各生成一次，随后P/S直接选择对应实体的已冻结数组。
- 不因方案名、训练seed或运行顺序重新抽donor。
- 未改变的实体在不同方案中的材料逐位一致。
- P/S虽为逐实体异质处理，仍各自真实共同训练一个MLP；不调用LLM，不拼接统一模型的逐实体预测。

材料完全相等时精确复用，不把“必须有diff”作为继续/冻结的门。材料不同但训练效果近似也是有效读数。

## 8. 训练随机性、缓存与预算

配对训练seeds固定为：
`20260918, 20260919, 20260920, 20260921`。

各方案同一seed使用完全相同初始化与父batch：
`batch_seed = 800000 + 100*model_seed + 9`。
沿用 `RandomState(batch_seed).randint(0,13856,size=(2000,64))`。
donor/增强材料在四个训练seed间固定；本包不估增强材料重采样或LLM方差。

每作业5方案×4seed=20格，3作业共60个逻辑格：
- 优先复用夜间包R的9个旧模型（前三seed×三作业），逐格核对父对、scaler、donor、batch/初始化配置和C评分。
- 缓存复用前允许且只需1次原种子重训核对：a55/R/20260918；对齐则作为已核对缓存重放，不制造第61个科学单元。
- 若权重不完全一致，先查环境/配置；不能混用不同训练协议。无法对齐则不复用缓存，在现有上限内重新生成所需格并披露。
- 只复用完整、配置和材料一致的真实工件；路径/数组/重放检查足够，不计算新hash。
- N/U/P/S如出现材料别名，可复用同job、同seed、同训练目标的模型；列明对应关系。
- 旧night包中的FreqMask模型不属于本实验方案，不拿来填格。

预算：
- 名义60逻辑格，复用9格且做1次重训核对时，新增拟合为52次。
- 无法复用时最多60次网格训练＋1次缓存核对；总拟合尝试硬上限64次，含最多3次重试。
- 每格最多重试一次，只限明确瞬态运行故障；数值/配置/数据错误先定位，不靠换seed绕开。
- 单拟合子进程300秒硬超时；整次运行含推理评分90分钟硬上限；整任务含实现与分析4小时。
- GPU被占用最多等待15分钟，不终止其他执行线；期间定期报状态。预算/等待耗尽时PARTIAL收口。
- 按近期46–51秒/拟合估算，52次约40–44分钟，61次约47–52分钟，另计适配与评分。这是估算，不是承诺。
- 0实验LLM、0API、0新Consumer超参数搜索；不自动追加seed、规则、分组或作业。

执行按job固定顺序a55→a65→a75；seed按上述顺序。方案基础顺序N/R/U/P/S，按seed序号循环左移0/1/2/3位。单GPU拟合串行、每格独立子进程。

## 10. 反馈估计与主次比较

主指标沿用原 normalized MSE 实体宏均值、48步均值、块内origin等权。
任一比较A→B：
`d(job,seed,block) = loss(A) - loss(B)`，正数表示B更好。

主要机制比较：S→P，在C_A工作负载上检验Pattern分组相对同规模随机分组的效果。
必要效果对照：
- R→P：条件构造相对当前基线；
- U→P：条件构造相对统一使用新规则；
- R→U：统一donor规则的效应；
- N→R：当前作业增强相对不增强的锚点。

每个job、每个block分开报告：四个配对差、均值、sample SD、SE、正/负/零计数。
n<2时SE为null；不得用32个实体补成32个独立重复。
完整n=4时可给固定终点、df=3的95% Student-t近似区间（临界值3.182446305）；标明只条件于固定材料、工作负载和训练程序，且小样本近似没有覆盖未来时间/增强随机性，也未校正多重比较。
不得使用“符号≥0.75且2SE”自动宣称显著；不执行按读数自适应追加到过门。

工作分辨率参考 `delta_job = 0.01 * mean_seed(loss_R_C_A)`，其公式预先固定；它只是1%实际效用参照，不是科学常数。对每一比较可描述：
- 区间整体高于+delta：当前工作负载上有候选改善证据；
- 整体低于−delta：当前工作负载上有候选伤害证据；
- 整体落入[−delta,+delta]：在上述近似下支持实际接近；
- 其余：方向/实际意义仍不确定。
完整保留连续值，不把等级当作后续Skill执行许可证。

三作业的均值只作等权描述；不要把12个seed-job、32实体或多个origin当成独立作业样本做显著性。C_A、C_B、E分列，不按E重选主指标/阈值。

## 11. 材料与贡献诊断

仅做与本假设有关的少量零拟合描述：
- R/U的donor绝对时间距离、相同小时比例、240点窗口重叠比例；
- 父与donor的X均值差/训练scale、X标准差差异、子对相对原父对的RMS变化；
- 每实体Pattern值、P/S所用规则、R/U材料是否相同。
- 预测侧完整32实体损失差向量；正贡献top2占全部正贡献、负贡献top2占全部负贡献，禁止除以接近0的净收益。
- 从C_A预定主比较固定top2绝对贡献实体，再在C_B/E检查同一批实体，不重新选top2冒充复现。
- 删除单个评价实体后的均值只作集中度诊断，官方分仍保留所有实体。

这些描述不自动识别物理机制，逐实体预测差不等于该实体训练材料的因果价值。额外相似性、聚类、回归、特征筛选均不在本包。

## 12. 收口判断：不设置能关闭整个方向的“oracle门”

报告首页逐项回答：
1. R与U是否真的产生不同材料？统一规则效应是否在当前预算内可辨？
2. P与S是否不同？Pattern分组是否比这一个固定随机分组有优势？
3. P是否优于R和U，还是统一规则已解释全部收益？
4. C_A的读数在C_B/E如何变化？是否主要依赖某个实体、时间段或训练seed？
5. 更值得追加哪一种证据：训练重复、另一个Pattern/构造假设、更多独立作业，或暂不增加投入？只提出一项，不执行。

允许以下性质的结论并存：
- 统一规则有效，Pattern增量未建立；
- 局部联合构造出现候选信号，值得后续形成/复用验证；
- 规则间差异在当前精度下不清楚；
- Pattern不命中/全命中或材料相同，本包未形成对应处理差异；
- 新规则或分组有害，保留负结果。

“Pattern候选信号”至少同时展示P相对S、R、U的实际比较及跨job情况，不得只挑一个有利对照。不预先承诺通过；不声称四seed或三个开发作业证明泛化。
零LLM的人写规则即使获益，也只算环境/机制证据，不算Source、Slow或A5正结果。
