## 4. 一步更新与参考损失的实现契约

theta0为同一份公开预训练状态，没有本地warmup。
每个材料p、父窗口k，都从theta0独立开始：
1. 恢复全部参数、影响前向的buffer和随机状态；清空梯度与缓存。
2. 新建Adam，参数如§1；optimizer状态不得跨块继承。
3. 用该窗口处理后的X和同一原始y计算预测MSE，反传一次、裁剪、更新一次。
4. 在固定P0参考输入上预测，保存C_A两个origin的逐实体损失与整体差。
5. 丢弃本次适配状态，再开始下一个块；不把所有块串成训练轨迹。

本包优化目标明确为：从192点X自回归预测48点y的MSE，归一化沿用固定T scaler。
模型保持eval模式关闭dropout，但单步更新期间开启autograd；eval不等于no_grad。
不额外逐窗口重新标准化，不让修复方案通过改变scaler改变任务。

Time-MoE的训练forward自带多预测头、内部损失与可选router损失，不能把其outputs.loss未经核对直接当本任务的48步MSE。
最小实现使用官方已有预测头，按官方生成的剩余horizon选择逻辑展开48步，保留梯度，不teacher-force未来真值、不新增预测头、不额外加router损失。
评分与更新使用同一种预测函数；不用带no_grad的generate结果反传。
先核对该函数在无梯度时与指定checkpoint官方generate的预测一致，报告最大误差；fp32容差atol=1e-5、rtol=1e-4。超出即修实现，不带错误结果进入主实验。

这是公开论文MSE描述下的明确实现选择，不能声称已确认与缺失的作者脚本训练目标逐位一致。
若之后取得作者脚本，报告差异，不在本包按结果悄悄更换损失。

定义：
    v[p,k,o] = L_o(theta0; fixed_P0_input)
               - L_o(one_step(theta0, X[p,k], raw_y[k]); fixed_P0_input)
    d[p,k,o] = v[p,k,o] - v[P0,k,o]

正d表示：针对同一父窗，修复版的一步更新比P0版更有利于参考任务。
必须同时保存v和d；不把“继续训练本身有效”误记为“修复有效”。
L_o是单origin的原始观测标签宏NMSE，仅作时间分解。同时用旧score_block直接计算整个C_A的L_A及v[p,k,A]、d[p,k,A]。
主分数使用L_A；缺测比例不同的origin不能先各自平均后随意合并，不能以两个L_o的简单均值代替L_A。

## 5. 块覆盖与完整材料代理分数

为了限额，不为几千个父窗逐一反传。每实体把按时间排序的合法父窗索引等分成4个连续stratum，各取中位索引；奇偶中位统一取较早者。
该规则只用T与合法索引，三个材料共用。一般每Job为4×实体数个估值块；不足4窗按资格失败，不补造。
抽样是本包测量手段，正式确认仍使用全部合法训练材料，不是给Fast新增采样动作。

记录每块覆盖的实体、X/y原始行号、stratum大小，以及三份X是否真的不同。
X逐位相同的配对允许复用同一更新结果，d必须为0；记录节省的物理更新，不伪报执行次数。

完整材料主代理：
    U[p,o] = sum_k (stratum_size[k] / total_legal_parents) * d[p,k,o]
    U[p]   = sum_k (stratum_size[k] / total_legal_parents) * d[p,k,A]
    U[P0]  = 0

这对齐训练池中均匀抽合法父窗的权重，而非强行把不同训练窗数量的实体等权。
它是分层代表窗的一步响应汇总，**不是**完整联合重训差的无偏或精确估计；交互和优化器非线性须靠§6实测。

同时落实LTSV的覆盖汇总：逐点取覆盖它的已估值块均值，再对覆盖区间汇总成实体/片段图；无覆盖点为null，不能补零。
该图只用于定位，不能把预测损失贡献或覆盖平均解释为单点因果价值。主选择始终使用上面的U，不在两种聚合间事后择优。
重叠窗、实体和两个origin不当作独立训练重复；本包不据其数量生成虚假的窄置信区间。

R_LTSV选U最大的完整材料；完全平局或差<=1e-12，顺序P0→P1→P2。
阈值只消除数值平局，不是显著性/采用门。
两origin排序冲突单列，不用“相信最后一个origin”解决。本包不会凭LTSV自动修复时间代表性。

### 6.1 同一个TSFM的有限预算真实适配：主确认

两个Job×三份完整材料×三个配对seed，18条实际适配。
都从原theta0重置；全参数Adam与§1相同，固定100次更新、有效batch=4、无scheduler、无早停、无checkpoint择优。
batch可微批累积，按样本数正确平均梯度；每次优化器更新之前只裁剪一次。
seeds固定20261201、20261202、20261203；由独立RandomState在完整合法池均匀抽父窗，三份材料的索引流逐位相同。

这是“预训练TSFM＋100步适配”这个明确Consumer的真实参照，不是原MLP的替代真值，也不是已证明收敛的TSFM最优训练长度。

- 它是否能比较这些直接修复版本？不变材料必为零只是检查，非效用证据。
- 同一TSFM真实适配的可辨差是否被代理捕获？参照区间跨零不能算“正确/错误”，另报描述性排序。
- 选中的方案后续更好吗？同C_A一致不等于E有效；单Job正号不证明普遍可迁移。
- 对当前MLP是否可用、实际是否省钱省时？这两项均需单列。

若同TSFM出现有用线索而MLP不支持，只能提出后续TSFM路线，不能替换现役Consumer。
若只改善当前context而C_B/E无益，问题仍包括参考时间的代表性，不把它记成Skill失效。
若差异小、参照不确定或代表窗覆盖不足，报告当前小规模无法识别，不能宣称LTSV整体无效。
不晋升Skill、不自动增加批次/seed、不开展全量论文benchmark。完成后由Planner依据四表安排下一包。
