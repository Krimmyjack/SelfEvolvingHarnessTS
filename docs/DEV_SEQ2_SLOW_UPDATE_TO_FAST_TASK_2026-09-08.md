本包是逐序列、已曝光 development 上的机制试验。主要对照是知识冻结 A 与知识修改 B。
它不拆分分组/归因/提示格式各自的贡献，不是完整 A5 或独立泛化验收。
候选在隔离开发分支中运行，不自动获得正式部署权。采用和仅测试要分开记录。

## 2. 本包明确允许的方法调整

### 2.1 输入与归因

沿用轻量分组，给出同 Task/Consumer 下可比的失败与成功对照、正确窗口特征、完整
程序参数、已到达 Support/delayed 读数及关键观察/探测/选择记录。缺测保持 UNKNOWN。
UID/窗口用于追溯与比较，不得被编译成按实体、数据集名或时间位置记答案的适用条件。

分组不是共同原因的判决。Slow 可选择有证据的子群、指出不同解释或弃权；不强制
解释最大组，不强制覆盖多数失败。现有五类故障保留为统计标签和事实提示，不再由
标签预先否决下面已授权的指导面，也不把所有修改强行宣称为已确认 SKILL_LIBRARY_GAP。

Slow 输出四项即可：事实引用、机制假说、一个具体修改、预期行为/效果及反证条件。
成功行为需要指出应保留什么。不得由执行者给出已知赢家、手工完成卡或指定正确归因。
不把本任务的示例和 Fable 的事后答案作为运行模型的“修复提示”。

### 2.2 精确编辑白名单

候选每次只改一个逻辑 surface，沿用已有编译器、分支与前置条件：

| 对象 | 本包允许 |
| --- | --- |
| 情境化指导 | `skill_library.entries/{skill_id}` ADD 指导型条目；现有指导条目的 `.body` 或 `.observable_applicability` PATCH |
| 观察指导 | `bootstrap_skills.entries/{skill_id}.body` PATCH 已有观察/准备 procedure 的指导文本 |
| 提议指导 | `candidate_policy.proposal_guidance` PATCH |
| 选择指导 | `candidate_policy.selection_guidance` PATCH |

只改软指导，不修改固定 Program 卡的执行体，不用 Frozen program marker 直供共享答案，
不增加 `supplies_candidates` 或 serving Scope 权限。允许建议公开 DSL 内的处理，但
最终程序仍由每条序列的 Fast 形成并按既有规则检查。
通用指导可适用整个合法任务人群；情境指导可以适用子群。两者都不要求完美成败分隔。

不开放 `instruction.core`、retrieval top_k、候选数设置、risk_guards、verification、
算子/特征计算器、Consumer、评分、训练/服务几何或任意运行时代码的模型自改。
研究者可做实现上述白名单所必需的最小接线；不以“0 核心文件”强行阻止必要修复，
但不能因此更换冻结合同或另建存储/哈希平台。若白名单中的现有路径缺必要接线，
包内补齐；若需扩大白名单或更换契约，停该部分并报告，不默默缩回只准 ADD。

候选编译到现有隔离 fork；父快照保留。失败不覆盖父版本、不删除仍合法的旧知识。
原始跨轨迹 Episode 只在 Slow/运行时侧；Fast 只读冻结指导和当前轨迹合法材料。

## 4. 两臂如何运行，如何避免又被旧 L2 卡住

- A：共同形成状态 + 原冻结知识，Fast 正常逐序列观察、探测、选择和执行。
- B：完全相同形成状态 + Slow 候选知识版本，Fast 同样运行。
- 同模型、工具、DSL、初始历史、当前反馈权限、人口与当地 Fast 预算。分叉后各臂承担
  自己的轨迹和成本，不互借对方新得到的探测答案。共享的真实确定性预测可缓存复用，
  物理成本与各臂逻辑评价量分开报，避免先跑臂承担全部缓存成本造成假效率差。
- 每个后续序列开新 Fast 会话。把前一轮 Slow 对话、反思长文本或原始 Episode 偷渡到
  Fast 不算 Skill 复用。必须确认修改字段确实进入 Fast 实际读取的面。

旧 L1/L2/L3 如可廉价复算则单列诊断，不决定候选能否进入隔离开发测试。
特别是不得只因覆盖 1/6、覆盖全部对象或旧程序在别处不再失败而跳过新 Fast 的测试。

### 验证、采用、继续测试的区别

u9 上先运行两个版本的真实 Fast。默认的本包保守“可采用”标记要求：读数可比且完整、
B 相对 A 的同人群 delayed 增益达到既有 MATERIAL、B 在该验证单元通过既有权威门。
不改常数、不改风险分母，不要求 Support 与 delayed 两面同时胜父，不回看全历史逐格否决。
这是本包新增的开发级指导采用规则，不包装成原生产规则或已获得 Shared Capability。

无论该标记是否通过，**只要有合法候选且仪器健康，都把冻结的 A/B 候选版本在 u10/u11
跑完**，让本包得到新指导的真实后续读数，而不是又止于代理门：

- 通过：记录验证后采用的开发分支及后续表现；不宣称正式部署许可。
- 未通过：B 明确标为未采用候选的隔离诊断分支；后续结果不得计作晋升/部署收益，
  也不得反过来追认 u9 通过。其作用是区分“指导没有价值”与“采用规则过不了”。
- 无候选/编译无法形成合法候选：记 NO_UPDATE_TREATMENT，继续该组父版本预定课程及
  另一组，不人工造 B，不把相同快照的随机差异算知识效应。

这是候选效果验证，不是为了通过验收临时改变风险政策。数据可比较但结果负，仍是完整结果。

## 5. 实际测什么

逐 (组、臂、单位、序列) 保留：实际读取的修改、观察/工具调用、候选及探测、最终
Program、是否 identity、Support/delayed 增益、受损与不可执行/缺测原因。
不要求另建追踪框架；复用现有记录，补足识别这些事实的最少字段。

主读数是 u10/u11 的全决策人群配对 delayed 效用差；Support、验证单元和形成段分开。
默认先逐单位平均，再对预定后续单位等权平均；A/B 使用完全相同 UID 集与分母。
任一侧存在未取得的必需读数，完整总体差记 UNKNOWN，另报配对可读子集及缺测覆盖，
不能悄悄把子集结果当全体。独立性按真实序列/窗口/训练模型的关系解释，不按行数扩大 n。
同时报告受损次数/比例、最坏伤害、覆盖、权威门、LLM/fit/时间。当前合法回退真实执行
为 raw 才记 0；仪器缺测不能记 0，也不能把候选可读子集均值与父版本全体均值比较。
重复读取不增加独立样本量；完整执行后的相同程序/相同输出也如实保留。

行为链至少区分：修改已加载 / 影响观察 / 影响候选 / 影响选择或交付 / 效果改善。
加载或检索不是“未使用”的同义词；文字变化不等于能力增量。没有行为差异时不要
把随机分数波动讲成学习；有行为变化却无益时也不要只报提案数。

保留正例回归读数，检查是否靠放弃大量处理降低伤害。当前既有风险修复若只降低伤害
而损失效用，照实报告取舍，不为该候选现场发明新效用函数。基线是 A 当时的真实
可执行策略，不事后指定一个更差的父程序或 raw。

## 6. 夜间执行与资源

建议本包总上限：2000 次 Consumer fits、2000 次物理 LLM 调用、6 小时墙钟，先到先停；
用户转发时若指定不同上限，以其为准。这些数是新包上限建议，不冒称历史剩余额度。
包括必要烟测、故障尝试和两组实跑；阶段间共享剩余资源，不再硬分 formation/boundary
额度。不设每格 5 次之类的小帽；保留超时、无进展重复调用检测和包级停止。
这限制失控，不要求耗满。两组及报告完成就停；正/负结果均不加第三组。

模型：使用用户指定的可用非 Flash 配置，优先其确认的 DeepSeek Pro；若该端点不可用，
可使用同项目已获准且可用的 gpt-5.6-sol。只限已配置/已授权服务，不新开账户或购买服务。
预检核对请求名和实际返回标识，不能凭 deepseek-chat 别名声称 Pro，不能静默回退 Flash。
整包固定一种模型；不能确认非 Flash 身份或两种均不可用，留配置故障收据并停止付费调用。
不显示、复制进报告或重新持久化密钥；使用已有安全配置。

顺序执行两组，复用之前的低内存/独立进程恢复方案；run_id 隔离输出但不造新平台。
关键节点即时落盘，恢复读取同一次调用结果，预算跨进程累计。不能删除已有 checkpoint
后重新抽样，也不能关闭用户的其他应用来腾内存。重复 OOM/确定性错误修不掉就收口。
传输暂态可按现有有界重试恢复；账户额度/权限错误不盲重试，不替换未授权模型。

候选弃权、负收益、未采用不停止整个预定包。只在信息泄漏、比较失效、边界外改动、
无法恢复的工程/传输故障或总上限处停止受影响工作。普通接线/记录问题自行修正并集中报。
生效方法改变后的混合配置不得并表；保留失败尝试，不用后次读数追认前次未知。
