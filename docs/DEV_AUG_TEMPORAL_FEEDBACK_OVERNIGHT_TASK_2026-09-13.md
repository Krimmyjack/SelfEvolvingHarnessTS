## 2. 估计对象和比较单位

Consumer 指完整训练程序：MLP、优化器、初始化/父batch随机性、2000步预算、权重与归一化；不只指网络架构。

每个作业 j、方案 k、训练重复 r，产生一份完整32实体材料和一个共享 MLP。
在明确工作负载 Q 上，比较：
    V(D_P; D_B | A,Q) = E_r[loss_Q(A(D_B;r)) - loss_Q(A(D_P;r))]。

B = 全体单步 TimeMixup；P = 全体单步 FreqMask。
本包统一 Δ = loss(B) - loss(P)，正号表示 FreqMask 更好；禁止混用旧 a94 报告相反方向的 Δ。

同一作业内的重复只估固定材料条件下的训练随机性。换作业重新截取 T、重建材料后，观察的是该构造方式在新的训练/时间上下文中是否延续；不是把同一份 D 的误差条扩大为跨任务保证。

逐评价实体的差值仅作贡献分解。它不等于该实体训练动作的因果贡献，也不能拼接不同模型的逐实体最优分数。本包没有 None，因此不重新裁定“增强相对不增强”的净价值。

## 4. Consumer、材料、随机性

完整复用增强线数值语义：

- 共享 MLP 192→128→64→48，ReLU，无 dropout/BatchNorm。
- AdamW lr=1e-3、weight_decay=1e-4，2000 updates，parent_batch=64；不早停、不挑checkpoint、不调参。
- scaler 仅来自各作业真实 T，每实体 mean/std；同作业内所有方案完全相同。
- 原始/派生各半权重，每父对总权重1；不改样本数、滑窗密度或权重语义。
- B 全体单步 TimeMixup，donor_weight=0.25；P 全体单步 FreqMask，mu=0.10。
- donor只来自同实体、同作业合法父对；派生样本不再作donor。没有第二步，没有服务侧增强。

训练 seeds 固定为 [20260918,20260919,20260920]。
对同一 r，两方案用同一初始化和同一父batch索引；父batch随机流与增强随机流分开。

为避免跨作业同时改变随机材料生成规则，三作业使用相同的增强随机索引安排：
- step1实体 i 的 seed = 900090+i，i按冻结roster的0..31；
- 每个训练 r 的父batch seed = 800000+100*r+9；
- 初始化 seed = r。
这是复用 a94 的随机流算术，不是复用 a94 的训练值。相同433父对形状下，各作业 donor/mask 的索引安排相同；真实数值与本作业scaler重新产生。
同一作业三次训练之间材料完全固定。记录完整 donor/mask 可复现信息；复用现有保存方式，不只存头5个，不新增哈希。

如果发现现有算子并非纯索引随机、上述安排不能保证材料重建一致，先修本包适配并如实记录，不改变算子语义。无法保证则该作业不可解释，不能作为时间差异证据。

跨作业同时改变了真实训练材料和后续评价状态，因此只能称“作业/时间条件差异”；不能唯一归因为训练漂移或评价漂移。各作业还共享随机索引，不将9个seed-job组合当成9个独立时间环境。
