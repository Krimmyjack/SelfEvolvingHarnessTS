## Problem Anchor (immutable)

After a natural forecasting conflict, can earlier parent–child Consumer-response evidence guide a useful, **safe** workflow edit on an **independent later encounter**?

## Method thesis

DEV-EDIT-TRANSFER-0 tests whether **historical edit-response information** improves chronological decisions over (i) information-matched **absolute-utility** history and (ii) **equal-budget fresh search**. Subtraction \(d_e=g_e(P')-g_e(P)\) is **not** a method: for a fixed parent and candidate set it preserves rankings in every context.

A non-equivalent rule must be specified before any claim that “deltas transfer.” Until that function is written down and shown to differ from centered absolute-utility estimation, the package only measures **whether any chronological one-edit headroom exists**.
