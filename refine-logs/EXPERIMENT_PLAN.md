# Experiment plan — DEV-EDIT-TRANSFER-0

**Does not authorize** live Agent courses, new Consumer fits, or sealed reads.  
**A (Agent vs fresh search) remains unmeasured** until a later authorized package.

## Frozen setting (block 0, before any scoring)

- Edit surface: **Workflow one-edit neighborhood** of the frozen P1 Common DSL (swap one operator / add-or-drop one impute step / order swap / one legal parameter). Include **no-edit/abstain**.
- Not in this package: Scope edits (Idea 20), new operators, per-channel Consumer.
- Risk gates: existing four lines (0.005 / 0.20 / 0.30 / MIN_TREATED 5) plus coverage floor.
- Statistical unit: **training cohort**, not origin-within-cohort (HEC-1 contract: origins reuse training).
- Donor vs recipient: separate training data. Extra origins = temporal reencounters only.
- Denominator: **all eligible conflicts**, including abstain / failed validation / no later window. Incomplete cache = UNKNOWN, not “no repair.”

## Blocks (must-run, in order)

### 1. Specification and cache audit — 0 LLM / 0 fits

Purpose: freeze neighborhood, chronology, donor/recipient split, selection rule, budgets, gates, denominator. Audit which parent–child pairs are already cached.

Stop: if every candidate “delta rule” is algebraically equivalent to \(\arg\max g_e(P')\) under the intended information, **cannot** claim representation advantage; proceed only as headroom audit.

### 2. Chronological headroom — 0 LLM; **new fits need authorization**

Purpose: at each eligible recipient conflict, select using **then-available** evidence, validate on an unused face, freeze, then score a later reencounter vs parent and identity.

Stop this edit family if **complete** finite-space evaluation finds no useful **safe** repair. A failed selector ≠ absent headroom.

### 3. Transfer comparison — 0 LLM; reuse readings; missing fits separately authorized

Comparators (same neighborhood, same current feedback):

| Comparator | Tests |
|---|---|
| Equal-budget fresh search | history vs search again |
| Absolute-utility history (matched information) | whether edit-response labels add anything |
| Simple deterministic transfer rule | Agent not required in this package |
| Parent and identity | separate \(d_e\) from operational benefit |

Stop the **delta-specific** claim if no decision-relevant advantage. Insufficient precision = inconclusive.

## First three runs

1. Read-only specification / chronology / equivalence / cache-coverage audit.  
2. Frozen deterministic headroom–validate–reencounter (after any required fit authorization).  
3. Transfer comparison on those paired readings (benefit, all four risk lines, coverage, feedback/fit cost).
